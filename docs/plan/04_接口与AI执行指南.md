# 固定通道接口与AI执行指南

## 1 新版接口优先级

本期使用附件contracts-demo.ts，不使用旧计划的动态通道、路径重建、复杂订阅消息协议。通道数目、模型和路面固定，避免两组在首次交付前实现大量暂时无用的通用能力。未来扩展时通过适配层迁移，数学核心独立保留。

目录建议：src/contracts由两组共管；src/app/viewer/player/charts由A组负责；src/engine/analysis由B组负责；fixtures与tests双方共享。第1天冻结通道顺序fl/fr/rl/rr、坐标、单位、配置和数据数组长度。

## 2 接口调用

UI传入runId和RunConfig，调用calculate；Promise成功后得到完整RunResult。所有信号按通道优先存储，每类4个Float32Array，每条32000样本。x参考加速度、u扬声器驱动、d原噪声、a实际次级声压、e残余。

波形由UI截取当前播放时间附近的原始数据；PSD与指标通过B组analyzeAt计算或读取B组预生成的同格式分析帧。UI不得自行另写一套声压级公式。分析窗不足时返回valid=false。

重新计算产生新runId，旧任务返回结果只允许丢弃，不能覆盖新任务。计算失败时显示错误并允许用户选择旧实验继续回放，旧实验名称和参数保持原样。实现每次只允许一个计算任务；先禁止计算中重复提交，可取消/Worker终止作为稳健性提升。

## 3 数据校验

配置固定sampleRateHz=2000、durationSeconds=16、adaptationStartsSeconds=2、road=asphalt、speedKph=60、algorithm=fxlms。taps只允许32或64，μ只允许0或0.08，首版种子仅11/29/47。所有数组维度、长度、有限性必须在引擎出口校验。无效参数不静默修正。

数据来源字段computed-browser、reference-replay必须显示在诊断区。导出配方时保存模型版本、路径版本、种子及全部参数。分析指标统一使用完整采样频带未计权RMS，频谱单独显示；不能用40至350Hz输入整形范围替代实际指标频带名称。


## 7 两小时人工工作块

建议15分钟明确当天输入输出，60分钟让AI生成并运行一个切片，30分钟人工复现与修复，15分钟提交与交接。AI任务自身若超时，先保存可运行结果，不继续叠加新需求。每个AI会话只负责一组目录；跨组契约变更由A1+B1确认后统一更新。

Git分支建议a/viewer、a/app、b/engine、b/analysis。一天至少合并一次可运行结果，不等两周结束再第一次拼装。任何重构若预计超过2个人工小时，先记录原因并比较最小修复，不能让AI在全仓库自由重写。
