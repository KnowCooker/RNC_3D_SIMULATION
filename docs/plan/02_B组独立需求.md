# B组四通道FxLMS交付要求

> 历史基线（demo-v2）：本文件保留两周阶段的范围和验收，不能限制2026-09-24恢复的完整目标。当前终点见[完整目标](10_FULL_GOAL.md)，A组最终交付见[统一标准](../coordination/A_FINAL_DELIVERY.md)；旧数值fixture及其回归要求继续保留。


## 1 必须保留的数学结构

固定I=K=L=M=4。I为轮胎源数，K为参考输入数，L为扬声器数，M为误差点数。每个扬声器由4路参考共同驱动，所以控制器有16组FIR。每个扬声器影响4个误差点，所以实际次级路径和估计路径都是4×4矩阵。

约定e=d+a，故权重按负梯度更新。u_l[n]=Σ_k,j w_lk,j[n]x_k[n−j]；a_m[n]=Σ_l S_ml*u_l；filtered-x为S_hat_ml*x_k；更新w_lk,j←w_lk,j−μ/4·Σ_m e_m[n]filtered_x_mlk[n−j]。权重使用当前样本误差更新后，仅供下一样本使用。

矩阵数组顺序固定：W[output][reference][tap]，S[error][output][tap]，P[error][source][tap]。所有卷积因果，不读未来样本；路径首个非零tap不得在负时间。参考算例S的最早非零tap是4。FxLMS学习中需要处理次级路径的原理可参照[MathWorks官方示例](https://www.mathworks.com/help/audio/ug/active-noise-control-using-a-filtered-x-lms-fir-adaptive-filter.html)，本项目自行实现完整矩阵版本。

## 2 首版参数

采样率2000Hz，时长16秒，前2秒关闭控制，2秒后开始学习；4路单轴参考，4个次级源，4个误差点。默认64个系数，支持32；数学阶数等于系数数减1。μ开放0和0.08，默认0.08；此数值只适用于随包提供的尺度和路径，不能作为通用稳定步长。

一种固定沥青路面、60km/h。四轮源彼此独立，使用40至350Hz整形噪声；本期不建立完整空间路谱/前后轮轴距相关模型，界面明确为简化激励。4个参考通道使用固定增益映射对应轮端激励，这与真实车辆的复杂混合参考有区别。

参考x单位设为m/s²；d/a/e单位Pa；u为无量纲驱动；首版路径P按参考输入到声压解释，等效轮胎源到参考的映射单独说明为单位比例教学设定。所有系数是合成值，不属于某款真实车辆。

## 3 噪声路径与指标

优先移植附件参考程序已有的固定FIR，不重新发明物理模型。初级路径长度24，次级路径长度16，16条次级路径均非零。S_hat默认等于实际S，本期不做在线次级路径辨识或估计失配调试。

波形显示x、u、d、a、e。PSD采用Hann窗1024点、50%重叠、正确单边谱与窗能量归一。时间指标使用0.5秒滑动RMS。声压级参考值20μPa，标记“合成SPL”。同窗降噪量10log10(mean(d²)/mean(e²))；四点总指标用功率均值后取比值，不直接平均dB。

首版验收统一使用未计权的完整采样频带RMS，以便直接对照附件；输入主能量在40至350Hz，但指标不得标成“30至400Hz频带降噪”。如果后续增加频带积分，另加一个明确命名的指标，不替换已冻结基准。

## 4 执行方式与最小接口

calculate(config)返回Promise<RunResult>；一次计算完整片段。首版允许Worker或分块让出主线程，不需要音频回调驱动算法。用户修改参数后生成新runId；A组不得显示已过期计算结果。一次只有一个有效计算任务，旧任务结果可丢弃。

RunResult包含配置、x/u/d/a/e、统一采样时标、后4秒指标及生成方式。音频可由A组将Pa样本按固定增益构建AudioBuffer，并使用音频系统重采样；若B组另生成48kHz/16kHzPCM，必须采用同一滤波和增益处理两路。不能把扬声器驱动u直接当作耳朵处的反噪声。

B组提供TypeScript移植及无UI验证器。随包的Python程序是参考实现，用于对照和提前制作回放数据，不要求部署时启动Python服务。

## 5 B组独立验收

| ID | 固定输入 | 通过要求 |
|---|---|---|
| B01 | 默认种子11、64系数、μ0.08 | 所有数组有限，e=d+a最大绝对误差≤1e−5Pa |
| B02 | 默认及种子29、47 | 后4秒平均功率降噪≥3dB，四点均改善；对照参考程序每点差≤0.2dB |
| B03 | 默认数据逐样本对照Python | x/d/u/a/e中有量纲转换时先对齐，RMS误差相对参考RMS≤1e−3；近零数组改用≤1e−6绝对误差 |
| B04 | μ=0 | u和a为0，e=d；显示0dB收益，不发生假收敛 |
| B05 | taps=32与64，重复默认计算 | 两档分别与参考匹配；同配置结果确定可重复 |
| B06 | 逐个输出输入单位脉冲，再把一条非对角实际路径置零 | 每个输出原先影响全部4点；置零后对应跨路径响应消失；正式版保留完整矩阵 |
| B07 | 错tap、负μ、NaN配置及计算异常 | 返回明确错误，不继续播放旧数据冒充新结果 |
| B08 | 默认片段计算与数据发送 | 目标机争取5秒内完成；不达标记录耗时，保留进度/取消及已验证回放 |

B08是待测产品性能目标，不能用附件Python运行时间替代浏览器测试。默认算例输出驱动峰值约1.13，限幅阈值不可随意设为1而改变参考结果；u是无量纲控制量，耳机PCM另做固定增益和限幅保护。

## 6 数值附件使用

附件含reference_mimo.py、golden_4x4x4.npz、verification.json、initial_256_samples.csv和驾驶位两路WAV。NPZ含完整x/d/u/a/e及路径系数；CSV给前256个样本用于简单检查，这些样本处于未开控制阶段，收敛验证必须读取NPZ或重新运行完整程序。

已经测试的数字仅是合成参考系统结果。三维应用、JavaScript移植、所有目标电脑和最终试听界面仍需按本文件验收。
