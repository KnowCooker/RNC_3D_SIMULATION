# 两周任务与验收

> 历史基线（demo-v2）：本文件保留两周阶段的范围和验收，不能限制2026-09-24恢复的完整目标。当前终点见[完整目标](10_FULL_GOAL.md)，A组最终交付见[统一标准](../coordination/A_FINAL_DELIVERY.md)；旧数值fixture及其回归要求继续保留。


## 1 人工工时上限

两周合计80小时。第1至第8工作日用于计划工作，共64小时；第9至第10工作日用于修复、回归和交付缓冲，共16小时。每个工作日每人2小时，不假定晚上额外补班。AI编码、人工给需求和人工验证分工明确，不能因AI回复较快而省略运行验证。

| 成员 | 16小时计划工作的分配 | 修复余量 | 两周合计 |
|---|---|---|---|
| A1 | 环境/接口2h，页面2h，图表2h，音频3h，联调3h，打包1h，测试3h | 4h | 20h |
| A2 | 车辆5h，交互3h，点位标签2h，道路1h，核显优化2h，联调与测试3h | 4h | 20h |
| B1 | 数学/接口2h，FxLMS移植6h，数值测试4h，参数/异常2h，联调2h | 4h | 20h |
| B2 | 激励数据3h，路径/固定算例2h，频谱2h，指标2h，接口2h，对照测试3h，回放/说明2h | 4h | 20h |

这些是采用现成参考程序、AI承担主要编码之后的目标预算，不是零基础团队手写全部代码的估时。若必须采购精细模型、学习Blender、替换技术栈或修复机器环境，先占用余量；余量用尽即调整日期或公开降低交付等级。

## 3 交付等级与触发条件

**第1周内部版**：默认实验可展示，模型可旋转，4×4×4数值正确，驾驶位可试听，控制前后曲线可比较。允许频谱、四座位试听切换、部分样式在第二周完成。不得称为完整验收版。

**第2周目标版**：总计划中的必交功能全部通过以下验收，在线参数重算和固定算例回放均可用。既能用于讲解，也能作为后续开发基础。

**演示保底版**：如果浏览器移植或重算性能仍失败，使用附件参考程序产生的真实结果回放，车辆、曲线、声音仍可交互。取消不能生效的参数控件，明确标“参考算例回放”。保底版不能算参数重算功能已完成，也不能伪称浏览器正在运行FxLMS。

若D5还没有默认演示，则D6起只修主流程，停止PSD以外的视觉提升和连续场试验；若D8仍有数值错、无法启动或无法试听，负责人应记录阻塞并决定交付保底版或延后目标版，不能强行写成全部通过。

## 4 整体必须通过的验收

| ID | 检查 | 通过条件 |
|---|---|---|
| I01 | 结构与通道 | 一辆纯电SUV、一种路面、4参考/4扬声器/4误差点；IDs一致 |
| I02 | 真正多通道 | 16组控制滤波器、16条次级路径；跨路径脉冲响应非零，符合B组测试 |
| I03 | 数值正确 | B01至B07通过；不能硬编码降噪值或改变e的增益作弊 |
| I04 | 操作闭环 | 选点、计算、播放、暂停、重播、参数重新计算可完成，无旧结果覆盖新结果 |
| I05 | 试听公平 | 原声/残余同样本、同增益、同时间偏移；可切换四误差点，未单独归一化 |
| I06 | 图表与声音一致 | 选中点、运行ID、时间一致；正常播放时偏差目标≤100ms |
| I07 | 核显可用 | 指定基础电脑实测平均≥30fps为目标；默认计算目标≤5s；不达标明确支持限制 |
| I08 | 稳定性 | 连续演示20分钟、重算10次、播放切换20次，无崩溃、无限队列或明显内存持续增长 |
| I09 | 交付可复现 | 第二台Windows电脑按README启动，至少断网复测默认演示；依赖/前提如实写明 |
| I10 | 物理表达诚实 | 标记合成教学数据、预计算回放、固定工况；不称为真车预测或连续三维声场 |

验收记录：日期、测试人、代码版本、电脑配置、RunConfig、实际结果、证据位置、通过/失败、遗留问题。截图和录屏用于交互，数值JSON/NPZ/CSV用于数学对照。

## 5 第一周后的扩展顺序

当前必交项全部通过后，再依次考虑实时逐块计算、一个有依据的声场切片、第二种路面、参考传感器改制、FeLMS、更多动力结构。每次只扩展一项并补对应测试。额外时间先提高稳定性，不急着增加菜单数量。
