## 设计决定

用户已选择 E「云境香槟」。此前 A–D、F–H 均为探索稿，不再与 E 并列为待选主方向。视觉决策以本次用户附件 `screens/01-overview-approved.png` 为准，首页保留原图，不再次生成改写。新生成的三张子页用于细化同一视觉体系；它们是本轮设计交付，不代表用户已经逐页签收。

本轮交付是页面效果图、可点击交互原型、组件样式与实施规格。原型以固定效果图承载视觉，透明热点和真实 HTML 浮层演示行为；不连接现有仿真、模型或音频引擎，不能作为已上线的产品页面或计算结果。正式开发须拆分真实组件、三维资产与数据，不把整张图当成运行界面。

## 必须逐项遵守的视觉约束

1. 环境：落日、湖面、远山、玻璃建筑与大理石反射地面；色温温暖，车身边界清楚。
2. 车辆：同一银色 SUV 贯穿外观、透明、声场与拆解；后续实装资产必须有一致的外观/内部/物理锚点，不随页面换车型。
3. 标题：左上产品名；首页标题“让每一段旅程，都更安静”，副标题“以数字孪生，洞察声音的本质”。
4. 导航：顶部横向“总览 / 声场实验 / 结构与布置 / 方案对比”；选中态为深褐文字与短香槟下划线。
5. 模式：左侧竖向玻璃胶囊“外观 / 透明 / 声场 / 拆解”；首页维持此位置与顺序。
6. 首页右上：大声场卡，透明座舱、色标、OFF/ON 与改善三列，右上角轻量进入箭头。
7. 首页中下：传递路径、结构布置、频谱对比三张玻璃卡，从左到右顺序固定。
8. 首页左下：海岸、山地、沙漠、雪山四张场景缩略图，整体包在一个横向玻璃胶囊中。
9. 首页右下：香槟渐变主按钮“进入声场实验”，箭头向右。
10. 材质：暖白磨砂玻璃、细白边、柔和阴影、香槟金主操作；正文深褐，不使用荧光科技边框或冷蓝深色后台布局。

## 页面一：总览

**目标**：让用户看懂车辆、场景、声场和分析入口，并在一个主操作内进入实验。

| 触发对象 | 动作与去向 | 状态保留 |
| --- | --- | --- |
| 顶部四项导航 | 进入对应页面 | 车型、场景、选点、当前实验与相机预设 |
| 外观/透明 | 原位切换车身显示；透明度在展开层调整 | 相机姿态，不改布局与结果 |
| 声场 | 切换有效场显示；若需细看进入声场页 | 同一次实验与播放时间 |
| 拆解 | 进入结构页，并选中拆装控制 | 当前车型、物理布局 |
| 声场大卡或主按钮 | 进入声场实验 | 当前配置；未运行给启动引导 |
| 传递路径卡 | 打开路径浮层，节点可逐个解释 | 选中路径类型与通道 |
| 结构布置卡 | 进入结构页并显示安装点 | 选中通道 |
| 频谱卡 | 打开频谱详情；进入比较时带入当前窗 | 座位、频段、计权、时间 |
| 场景卡 | 打开场景设置并确认路面配置 | 旧实验仍标原身份；新配置需运行 |
| 右上更多 | 展开显示偏好与帮助 | 偏好独立于声学参数 |

## 页面二：声场实验

三维车占左侧约 65%，右侧约 33% 为一体化玻璃分析面板；左下是短配置控制台，底部为统一回放条。保持湖畔展厅而不换成黑色实验仓。

- 点选驾驶、副驾、后左、后右的测量位置：显示探针、座位读数、频谱。座椅数量不等于测量通道数量。
- 原始/残余：同一固定声压色标。改善量另用零中心发散色标，正值表示原始减残余后改善，负值为变差，图例明确方向。
- 水平/纵向/横向切面：方向按实际三维坐标定义；水平平面与地面平行，不把竖直面标为水平。可拖动位置，也可输入数字。
- OFF/ON 比较：锁定车型、布局身份、声源工况、座位、时窗、频段及计权。允许观察改善、零改善和局部变差。
- 道路、车速、声源频段/参数等影响计算的改动使结果失效；仅切片、相机和已存在数据的观察方式变化不重启计算。最终参数支持范围按实时契约。
- 播放条只有一个时钟。暂停、跳转、倍速联动场图、图表和试听；改变相机不改变时间。
- “保存方案”：保存完整配置、运行标识和有效时间窗；无结果或过期结果不能保存成有效方案。
- 图中 75.8/61.9/13.9 dB 为示例。正式数据由真实引擎提供；当前教学尺度与实车标定分开说明。
- 示例频谱的可见上限取真实采样率与分析带宽，不照抄母图中的 10 kHz。

## 页面三：结构与布置

保留同一环境，中心展示车辆结构；左侧为部件树，右侧为安装点检查器，下方为拆装滑杆与路径条。

- 部件树与车体双向选择；悬停轻描边、单击固定、双击聚焦。隔离显示可恢复。
- 拆解程度 0–100% 只控制显示分离；逐件拆解、逆序回装与恢复相机相互独立。原型滑杆演示状态，不生成机械运动计算。
- 参考传感器、误差麦克风和扬声器使用颜色、形状和名称三重区分。安装点必须来自同车核实几何。
- 可编辑的安装点/启用项以契约支持为准；未支持的字段显示只读与原因，不给出无效保存。
- 位置用车身坐标系，单位清晰；爆炸图的显示位移不得写回物理位置。
- 布局改动可撤销，保存后形成新版本，原实验失效；“保存布局并运行”进入重新计算流程。
- 路径节点“路面→轮胎→悬架→车身→座舱”分步讲解。路径动画是解释层，数值必须绑定真实通道/H/S。

## 页面四：方案对比

同一暖白玻璃体系，先给条件条，再给左右并排 A/B，底部放曲线、座位/频段矩阵和结论报告。

- 区分“ANC 关闭/开启”与“方案 A/B”；A/B 可以都开启 ANC，只改变指定设计变量。
- 示例 A 平均残余 65.4 dB，B 为 61.9 dB，改善示例为 3.5 dB。它与首页 OFF/ON 的示例 13.9 dB 含义不同。
- 比较前校验所有必须一致的条件；布局作为目标变量改变时，可比较性以实际物理测点映射与模型约束为准。
- 矩阵若采用 B−A，负值表示更安静，正值表示更吵；必须明示符号。不要与“降噪量=原始−残余”的符号混淆。
- 报告预览包含观察、结论、局部变差、配置差异、时窗、来源和限制；不自动生成“最佳方案”的绝对判断。
- 导出前预览范围；缺方案、缺数据、条件不一致时显示原因及恢复入口。
- 原型只导出带“设计示例”标识的文本，不代表工程报告或真实实验数据。

## 状态设计

| 状态 | 界面行为 | 可恢复路径 |
| --- | --- | --- |
| 未运行 | 车辆可观察，数据处显示说明而非伪造热图 | 运行实验 |
| 正在计算 | 真实阶段/不确定进度指示；主操作防重复 | 取消/重试 |
| 结果有效 | 读数、场帧、谱图共享实验身份 | 保存/回放/比较 |
| 配置已改 | 明示旧结果失效；冻结旧快照的身份 | 重算/撤销配置 |
| 无有效场 | 说明帧缺失、布局或模型原因；不补装饰场 | 调整/重试 |
| 布局未保存 | 显示草稿；离开时给保留、放弃、取消 | 保存/撤销 |
| 条件不一致 | 展示差异，不展示误导差值 | 对齐条件/回实验 |
| 无方案 | A/B 空位说明与保存入口 | 返回实验保存 |

## 组件规格

- 画布暖白底：#F6F1E9；主文字：#2F281F；次文字：#716657。
- 主色：#B68B55；浅高光：#F5DEB4；深端：#87613C；风险色：#A64C39。
- 面板：rgba(248,243,235,0.82)，背景模糊约 22 px，边框 rgba(255,255,255,0.8) 1 px；无 blur 支持时使用不透明暖白。
- 主面板圆角 28 px；内卡 18 px；按钮 32 px；输入 14 px。间距 8/12/16/24/32。
- 正文 16 px，次信息 14 px；工作页标题 24–28 px；首页标题 44–52 px。数据数字用等宽数字。
- 正文用系统中文无衬线；仅主宣传标题可用宋体衬线。不能把宋体用于高密度参数表。
- 主按钮悬停增亮，按下内收约 1 px；不依赖发光表示唯一状态。键盘焦点独立可见。
- 过渡 160–220 ms；页面/相机过渡约 350 ms，可取消；减少动态模式去掉相机漂移与装饰动效。
- 图表使用红/蓝并配线型或标签；高热红色不挪为主题色。图例在所有环境可读。

## 交互原型范围

index.html 为热点式页面原型：
- 四页跳转及对应入口；
- 场景/参数/视图、探针与切片设置浮层；
- 部件选中、拆装程度、安装点、撤销等状态；
- 路径节点解释与频谱说明；
- 运行状态演示、方案保存、可比条件与示例报告导出；
- 交互标注和组件/状态样式预览。

背景效果图为固定画面，不实时生成 3D 车、热图、道路或 ANC。控件状态与示例读数必须标识，不让原型被误认为生产仿真。

## 响应式与性能实施边界

- 主要设计与确认基准为 1672×941 / 16:9 桌面画板。
- 大于 1440 px 保持首页构图；工作页在 1200–1439 px 收窄侧面板，车身舞台优先。
- 小于 1200 px 的正式产品将分析面板收纳为抽屉、模式栏变横向；四场景横向滚动，保持可操作字号。
- 手机正式版需独立的车辆/控制/结果分区，不能只缩小桌面图。本轮原型可在窄屏查看图与浮层，但不宣称已交付真实移动版。
- 正式产品按目标核显设置画质，车体/热图需要真实性和性能共同验收；不能为达到图中材质而破坏实时操作。

## 实施分工与不变的边界

A1：导航、玻璃组件、布局、配置与状态、统一时间、曲线/比较/报告；  
A2：湖畔展厅与四环境、同车模型/结构、相机、透明/剖切/场渲染和点选接口；  
B/指定集成：真实声源、路径、MIMO、有效场帧、指标与比较身份。

设计包不自动认领或改动这些角色的源码。正式开发前按仓库开放 PR 与角色交接恢复状态，不能让设计样例覆盖已有真实算法结果。
