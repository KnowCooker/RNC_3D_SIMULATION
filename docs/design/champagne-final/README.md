# 云境香槟 · 产品页面与交互设计

版本：E-FINAL-1.0 · 2026-09-30 · A1

用户已选定云境香槟风格；首页直接使用用户批准的原始图片，没有重绘。其余三页是在相同风格下补全的页面方案。本轮交付设计与可点击原型，尚未替换项目正式应用。

## 查看

解压后双击 `index.html`，或在目录运行 `python -m http.server 5194 --bind 127.0.0.1`，访问 http://127.0.0.1:5194/ 。无安装、无外部图片依赖。

- 顶部切换总览、声场实验、结构与布置、方案对比。
- 点击图片中的按钮、卡片和道路缩略图，打开相应操作；“交互标注”显示可点击区域。
- 下方“当前交互状态”显示实时控件状态；“组件与状态”展示按钮、输入、等待、失效和不可比样式。
- 页面缩略图及“查看原图”可查看独立效果图。

## 演示顺序

1. 总览 → 点击“进入声场实验”。
2. 场景与工况 → 修改道路或速度，观察“配置已改 · 需重新运行”。
3. 演示运行 → 保存方案 A；修改参数后再次运行并保存 B。
4. 方案对比 → 查看条件差异，条件不一致时禁用报告导出。
5. 结构与布置 → 修改安装点；切换页面时演示保留草稿、放弃或继续编辑。
6. “组件与状态”查看实际 HTML 控件设计，Esc 关闭浮层。

## 实现边界

背景车辆、场景、热图与读数是固定效果图，不会随控件重算；切片和爆炸浮层使用简化的 CSS 示意。播放、运行和相机是状态演示，不包含实时三维、音频或声学求解。JSON 报告明确标记“设计示例”，不是工程结果。

75.8 / 61.9 / 13.9 dB 等仅用于视觉排版。生产版本必须由真实数据计算、校验频段与计权、绑定通道和测点。生成图可能包含示例性部件、座位或传感器数量，应以项目接口契约为准，详见设计规格和 QA。

当前批准范围为视觉方向和首页母版；新增子页是本次设计交付，不等于用户已逐页签收。以本包为开发依据继续细化，不再回到八套风格投票。
