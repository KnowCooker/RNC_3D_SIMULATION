## 素材、单位与循环

从已逐样本验证过的原始提取`../实测数据分析/recordings-original.npz`读取四路耳旁初级噪声，不读取reference数组。对应关系如下（通道号从1开始）：

| 虚拟声源位置 | 实录素材 |
| --- | --- |
| FL轮端 | 主驾左耳，49路 |
| FR轮端 | 副驾左耳，53路 |
| RL轮端 | 主驾后排左耳，51路 |
| RR轮端 | 副驾后排左耳，55路 |

这是用户要求的等效轮端映射，不是原录音传感器装在轮端，也不是实测声源逆识别。原数据单位V、未校准；四路去直流后用相同257点Kaiser低通（截止900Hz）抗混叠，从4kHz降至2kHz，统一除以四路合并RMS，保留相对幅度和同步关系，不平均双耳、不独立均衡每一路。准备工具、参数/源哈希、滤波器频响见`prepare_recorded_noise.py`和`recording-preparation.json`。1kHz以上最大约−94.9dB，800Hz以内通带最低约−0.000124dB。

运行资产`src/team-b/lab/data/recorded-primary.f32`为4×80000个Float32及16字节头，共1,280,016字节。SHA256为`c3bcc4ffcea96268032403eb01a0743f822701d6958bebc979752f93283d421a`。由integration Worker按需加载本地打包资源，B核心只接受数组。缺失/无效数据明确报错，不静默退回随机声源。

四路使用同一个0.2秒升余弦交叠窗口，首尾合成39.8秒周期；常规区直接读取素材样本，交叠区平滑混合。当前周期从原0.2秒开始，末端混合原39.8～40秒与0～0.2秒，再接回0.2秒。不会在接缝处重置W、源计数或传播历史。输入会周期重复，不能称为无限新噪声；固定1.28MB素材与有限仿真/音频缓冲常驻，不积累全程波形。内部600秒限制保留。

q标为“相对幅值”，x仍由教学R合成，未接入实录振动。速度/粗糙度/胎面/温度仍作教学幅度缩放；实录模式保持原频率，胎压控件禁用。随机谱形模式保留原参数规律，旧配置省略sourceMode时继续使用旧随机算法。

## 初级路径与频谱验证

实录噪声已带有车内谱形，不再套用原255点随机源整形、129点振动转噪声整形或[0.72,0.28]额外低通。初级H保留车型、地板辐射点、距离衰减、声速、直达和两条早期反射；用17点Blackman窗sinc分数延时，附加8个因果样本延时。

等效空间耦合为`0.05 + 0.95 exp(−[(x−x_seat)/0.4]²−[(z−z_seat)/0.6]²)`，seat为对应麦克风位置。对应声源主导该座位，同时保留全部交叉路径；任意场点复用相同路径。此权重是为保留各座谱形构造的等效包络，不能当作真实轮胎声辐射指向性。空间值来自信号逐路径求和，不插值四座SPL。S、16条交叉路径、NFxLMS梯度与理想S_hat=S假设均未改变。

固定教学幅度增益4.3619057736237865，使40km/h、BEV、默认几何、1～39秒四座A功率平均为60dBA；与RNC效果及当前运行时长无关，不是实录V/Pa校准。

独立Python审计实际TypeScript输出：1秒Hann Welch窗、50%重叠、忽略首尾1秒，仅PSD窗口去均值；按1～900Hz归一化，在1–20/20–50/50–100/100–200/200–350/350–600/600–900Hz七带计算功率占比的平均绝对dB差。目标为对应四个左耳原始录音，而非原先八耳合并谱。

| 目标 | 旧随机谱形模式 | 实录声源＋新H |
| --- | ---: | ---: |
| FL | 4.028 dB | 0.525 dB |
| FR | 1.435 dB | 0.714 dB |
| RL | 1.532 dB | 0.513 dB |
| RR | 4.180 dB | 0.623 dB |
| 四座合并 | 1.126 dB | 0.430 dB |

原始数值见[spectral-comparison.json](spectral-comparison.json)，图见[spectral-comparison.png](spectral-comparison.png)，教学幅度及四车型/拓扑结果见`simulation-comparison.json`。比较基于这份40秒素材及默认几何，不是独立车辆/新工况验证，也不是对原波形、实测通道相干性或真实降噪收益的完整重现。

首次仅取消129点整形、继续用原几何混合与两点分数延时，合并七带误差为3.467dB，四座为2.651/5.299/3.464/8.002dB，明显削弱高频且冲淡座位差异，因此改为上述局部主导/17点延时。该调整以噪声谱形为目标，没有使用控制后降噪量来拟合。实现期间修正过一处负号与指数运算的语法优先级，未放宽测试容差。
