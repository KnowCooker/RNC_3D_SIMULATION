原页面纵轴为`10log10(PSD)`，参考1 Pa²/Hz，不能当作dBA读取。本批由B分析端另返回`spectrumDb`：声压以(20μPa)²/Hz为参考，显示dBA/Hz或dBZ/Hz；q/x/u仍为单位参考的Z谱。A端直接绘制B计算的密度级，不自行计算声压级。原始线性PSD保留兼容。
