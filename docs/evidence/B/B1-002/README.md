## 范围与方法

对应任务表的 **demo-v2**，使用 B1-001 五算例作完整回归底座；不将旧版前2秒关闭控制的要求施加到默认立即学习的 lab-v3。冻结原始路径是对称矩阵，单靠默认结果不能区分部分转置错误，所以新增有符号、非对称、多延时的 P/S 测试输入。

`tests/helpers/engine-harness.ts` 把当前真实 TS 模块转译为 CommonJS，在独立函数作用域内提供固定白名单依赖。仅测试环境替换数据工厂；运行文件和冻结数据不被写入，不新增生产注入接口。无替换模块与普通生产入口的全32000点 x/u/d/a/e 及指标必须严格一致，防止验证只测到一份另写的控制器。

独立期望值 `directPrefix` 使用 W[reference][tap][output]，逐样本直接计算卷积及负梯度；不复用运行代码的滤波参考数组、补零缓冲或 `convolve`。学习前 W 为0，计算4000～4049样本，并比较完整0～4049前缀；人工非对称输入只用于识别索引和时序，不能当成车型声学参数。
