## 行为

1. 新版lab实验从0秒开始学习。零初始权重和路径延时仍保证因果性，不承诺第一个采样点已有降噪。旧lab配置允许2秒以复现历史，旧demo-v2默认与Python fixture完全不变。
2. 四座位分别绘制总声压级（全采样频带、不计权，参考20µPa），直接使用B分析的primarySpl/residualSpl；原声灰色、残余绿色，使用共同纵轴范围。首个有效0.5秒窗口出现一个真实点，不填充虚构初值。
3. 曲线只显示截至播放时钟的数据，暂停冻结、回放定位会截断未来数据；实时模式保留最近120秒，有界存储。首窗前与能量底限显示等待/无效提示，null不替换为0。
4. 波形与PSD叠加原声，同一座位/时刻的声压共用尺度；q/x/u等不同量纲的信号明确使用原声右轴，参考试听座位。时间轴为绝对实验秒数，频域横轴为真实FFT频点（2000/1024 Hz间距）；PSD单位使用dB re 1 unit²/Hz。
5. RNC ON选中听e，取消听d；不重算、不改变播放位置、学习状态或图表所选信号。按钮沿用已有播放器共同增益和交叉淡化。左侧算法开关仍决定实际计算，与试听按钮分工不同。
