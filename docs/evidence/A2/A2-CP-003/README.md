## 实际验证与复现

最终同版结果：`pnpm check`退出0，180/180测试通过（含A2共40项），类型、源码边界和构建通过；Chrome49项浏览器检查通过，无JavaScript异常和失败资源请求，运行请求均为本地资源。包括两次真实预计算A/B、真实评审摘要下载、持续Worker播放时钟推进/暂停/恢复/结束，以及1024/740/390宽度下无横向溢出。桌面四页和窄屏截图已人工查看。`git diff --check`通过；已有构建大块提示保留。

`check.log` 保存最终 `pnpm check` 原始输出与退出码；`browser-results.json` 保存最终浏览器逐项结果。`browser-check.mjs` 在本地生产服务5197端口运行，使用独立真实 Chrome 和实际 Worker，没有用伪造结果替换计算。

## 范围与差距

- 这是使用实际模型与控件的网页重构；模型及环境的摄影级细节仍与母版有差距，不声称像素级复刻或原厂CAD精度。
- 本轮保留上一轮 P7+ 外观作为默认展示，未把其改成母版图中的未知银色SUV，也未重做其他四款车。
- 品牌车声学配准、原厂内部结构、四真实车型精度、目标核显性能和第二台设备完全断网验收仍待完成。
- 海岸为本地许可HDR远景；另外三环境是程序化景物，不代表冰雪/沙地等新接地物理。所有主题变化不改变B组数值。
- 首页无有效品牌车场时使用带明确含义的布局示意及空态，不生成装饰性热图；有效教学实验读数与频谱使用同窗结果。
- 报告保留现有评审摘要语义，不冒充完整原始信号导出。
- 既有构建大块提示仍在；软件播放时钟检查不替代实物音画同步和目标设备帧率验收。
