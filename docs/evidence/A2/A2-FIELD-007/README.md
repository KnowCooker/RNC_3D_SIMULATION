# A2-FIELD-007 · 自然过渡与连续车内声场

2026-10-01 · Role: A2 · Identity-Source: user-declared · Codex 代 A2 执行。

本批按用户要求改善页面过渡与实验声场的可读性，使用 interactive-3d-atlas。在上一批五车模型和云境香槟环境的本地成果上继续；无 Git 提交或上传，新远端认领未发布。

## 实现

- 页面面板 260ms 淡入、对话框 220ms 打开/110ms 关闭；相机 420ms 球面缓动，保持从当前姿态衔接。手动拖动取消镜头过渡，快速切页以最后选择为准，尊重减少动态偏好。
- 用三维纹理与 48 步体积积分取代稀疏球点；三轴切片逐像素插值并显示 3dB 等值线。连续显示来自原有 7×5×8 共 280 个真实查询点，没有新增声学精度或虚构热点。
- GPU 插值采用相对 60dB 的声能，之后转换回 dB；不是直接平均 dB 或顶点 RGB。无浮点线性过滤时改手动三线性/双线性采样。
- 同窗改善为相同点/相同时间窗的 d−e，蓝绿代表改善，红色代表变差。标准绝对色标 30–80，改善色标 −10…10dB。增强按钮同时锁定原声/残余的共同范围，以及零点居中的有符号改善范围，不随模式单独归一化。
- 声场控件、图例、范围、真实探针移至右侧分析区，避免遮挡座舱；扩大座舱取景，增加俯视、透明度调节。原声/残余和切片切换保留手动视角。探针显示最近真实采样点，不把屏幕插值冒称新增求解结果。
- 当前数据帧直接显示，暂停时不制造流动；改变剖面继续走已有实际查询和过期帧隔离流程。

## 使用与限制

打开 `http://127.0.0.1:5197/`，在“声场实验”运行P7+实验，使用“同窗改善分布”“增强局部对比”和“头部水平切片”，再点“俯视座舱”或旋转模型，点击声场查看读数。右侧可滚动到座位指标、空间改善证据和曲线。
