## 改动与边界

- 原创教学 SUV 的前脸表面沿横向及纵向转折，车灯、灯腔、格栅和下保险杠由同一前表面方程定位；后尾门改为有横向曲率的闭合网格，贯穿式尾灯、两侧灯腔、牌照凹区和保险杠贴合其表面。替换了原先多块直板/圆角盒，不新增声学或车辆制造事实。
- 前后表面及饰件属于原有 `hood`/`tailgate` 部件，可随爆炸、透明/隐藏和剖面一起变化；新增网格由模型统一释放。四轮、五座、RNC 硬件及物理安装坐标、部件 ID 和 viewer API 均未改。A1/B/shared/integration 没有本批修改。
- 车身其他区域仍有明显程序几何痕迹，前后视图也仍达不到用户指定的游戏参照精细度；本批仅缩小大面积平板和浮动灯件的局部差距。不能以三角数下降推断视觉质量已经过关。
