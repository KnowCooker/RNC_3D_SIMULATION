|车型|本批修正|仍需解决的外观差异|
|---|---|---|
|P7+|窗下缺失蒙皮、C柱、五臂厚轮面、主灯浅凹和前脸鼓度|前后包围曲面与转角、完整透镜结构、尾灯/尾翼截面仍为近似|
|X9|轮拱侧围连接、灯腔圆角、前包围饰件、后风挡下蒙皮|滑门/侧围曲率、前脸倒角与导流口、玻璃和D柱边界需高精重建|
|L03|分叉厚轮面、连续侧围、去除不匹配的下灯腔凹陷|灯具转折及光学结构、窗线、前后包围细节未与实拍一致|
|M03|花瓣厚轮面、T灯圆角、侧围/后风挡连接|灯腔与车头曲面匹配、尾部包围及玻璃反射轮廓仍有差异|
|GX|连续大侧围、纵向前后脸曲率、后风挡下封闭|前脸转角、上车体/D柱、饰条和轮面微结构仍近似|

五车仍为原创程序化照片参考模型，不是原厂CAD或扫描。名义尺寸及交互通过不等于实拍一致；内饰继续沿用已有有包装约束的近似结构，未冒充实车维修或有限元模型。
