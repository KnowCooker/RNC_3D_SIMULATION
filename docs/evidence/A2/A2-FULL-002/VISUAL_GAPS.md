# A2 视觉差距与下一轮独立任务

评估日期：2026-09-24。依据 [A组最终交付标准](../../../coordination/A_FINAL_DELIVERY.md) 的 A2-F1/F2，以及相关 F3/F7 门槛。评估对象为本目录四车型、座舱、剖面真实 WebGL 截图和本轮完整页面改制截图；基线为 `79df17b553571ce8b87dea95ee2b5b717e0e66f6` 后冻结的本轮改动，最终归档提交与运行哈希由集成报告绑定。本次只评估和写文档，没有修改源码或执行构建。

**结论：四类结构与基本座舱已具备可运行的教学实现；A2-F2 的参照精细度与完整视觉对照尚未通过。** 本轮明显提高了材质、局部曲面和剖面质量，但图片仍显示较强的基础几何组合感。未取得同视角的《地平线》模型截图或获授权高精度参考资产，不能作出“接近”“达到”该品质的判定；三角数、正确计算和改制测试也不能替代视觉验收。

## 4. 建议下一独立 A2 改动批次

建议下一任务命名为 **“公共外壳与座舱形态升级 + 四车型固定视角证据”**。优先解决表中 P0 的公共曲面/接缝/座舱，再补 V1–V4 四车证据；这是可在 A2 自有目录内完成、不依赖 A1业务重写的有界批次。它不能直接关闭整个 F2。
