# A2-FULL-014 四车型共用车侧、车顶与座椅形态

状态：A2 局部实现及本机验证完成，待 PR 审查；A2-F2 最终视觉质量与 A 组最终交付仍未通过。基线是 A2-FULL-013 已提交 `5ab99a0`；本批经验证源码 SHA 在提交后固定，不用未来 PR HEAD 代替本批版本。

## 变化与肉眼核对

- 将车顶两侧悬空的圆管替换为贴合车顶与侧窗上沿的闭合肩部，车顶轮廓在四车侧面与斜顶视角中连贯。门外板增加上部肩线与下部收分，轮拱后方增加闭合深色内衬，门槛条减薄。模型仍为原创教学 SUV，不声明量产车型比例或零件精度。
- 五个座椅保持前 2 后 3 与原部件 ID、安装位置；坐垫前缘/边缘收分，靠背及头枕形态稍圆润，嵌片色差收敛。未移动四 MIC、四门扬声器、四轮或参考安装点。
- 轮胎装饰槽环分段从 40 减至 24，留出车壳几何预算。四车三角数由 ICE 46,460、BEV 46,448、HEV 48,704、EREV 49,376 变为 ICE 45,364、BEV 45,352、HEV 47,608、EREV 48,280；数字仅作资源预算，不作视觉达标证明。
- 固定机位肉眼检查：侧面车顶不再有明显脱开的长条，轮拱内部颜色更收敛，座椅嵌片不再过亮；车侧仍较平，立柱、轮拱、后部和座椅仍偏教学简化。游戏参照精细度明确未通过。
