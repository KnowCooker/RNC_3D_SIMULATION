## 变化与肉眼核对

- 将车顶两侧悬空的圆管替换为贴合车顶与侧窗上沿的闭合肩部，车顶轮廓在四车侧面与斜顶视角中连贯。门外板增加上部肩线与下部收分，轮拱后方增加闭合深色内衬，门槛条减薄。模型仍为原创教学 SUV，不声明量产车型比例或零件精度。
- 五个座椅保持前 2 后 3 与原部件 ID、安装位置；坐垫前缘/边缘收分，靠背和头枕改为闭合曲面，嵌片色差收敛。后排三座共用坐垫基座，移除相邻座位间重复的高侧翼，近景可直接辨认连续后排。未移动四 MIC、四门扬声器、四轮或参考安装点；新增模型检查四个 MIC 均在指定头枕 0.1 m 内。
- 轮胎装饰槽环分段从 40 减至 24，留出车壳几何预算。四车三角数由 ICE 46,460、BEV 46,448、HEV 48,704、EREV 49,376 变为最终 ICE 45,416、BEV 45,404、HEV 47,660、EREV 48,332；数字仅作资源预算，不作视觉达标证明。
- 固定机位肉眼检查：侧面车顶不再有明显脱开的长条，轮拱内部颜色更收敛，后排由独立方块底座改为共用基座；车侧仍较平，立柱、轮拱、后部和座椅仍偏教学简化。游戏参照精细度明确未通过。
