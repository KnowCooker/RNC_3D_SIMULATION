# A2-FULL-016 · 路面与三维声场可读性

本批为用户指出的三维舞台 UI、单一路面和声场不直观问题提供 A2 侧改进。道路现有平整沥青、粗糙沥青、碎石三种**视觉材质**，通过车间/道路上的叠加控件切换；海岸道路还增加了实例化岩石与沙丘草。材质均由本地确定性 Canvas 纹理和 Three.js 几何生成，无外网模型请求。**路面视觉选择尚未改变 B 组的噪声源参数**：目前左侧 `路面粗糙度` 仍是声学计算唯一输入。A2 已提供可选 `roadPreset(surface, roughness)` 回调及 0.6/1.2/2.2 建议值，均符合当前滑杆步长；需 A1 在其拥有的实验配置中接入、触发旧实验失效与重新计算，再验证路面和声学一致性。当前控件明确显示这一限制。

声场的 `三维采样体` 模式现在同时绘制 X/Y/Z 三张正交热力切片和 280 个采样点；三个单独切片仍使用原真实 Worker 返回的相应点位，面内为顶点颜色插值。开启场后相机转至车内可辨的后侧斜视角，默认聚焦声场；用户可切回硬件叠层。HUD 显示原声/残余声、当前时间、280 点的实际范围、最高采样点、固定 30–80 dB SPL 色标；点击热力面读取最近**真实采样点**的 SPL 和坐标。HUD 不对无数据或位置不匹配的帧显示旧值，也不把色片内插值称作新物理解算。

真实页面脚本：[qa-road-field.playwright-cli.js](qa-road-field.playwright-cli.js)。1600×900 下三种路面按钮均选中成功，视觉切换后物理粗糙度仍为 1（有意记录未联动）；ICE 默认配置 5.00 s 原声场 280 点范围 70.2–75.6 dB SPL，残余场 280 点范围 63.6–75.8 dB SPL，探针读取 `(0.00, 1.48, -0.33)` m 处 67.4 dB；聚焦模式硬件标记 0，退出后 16；360×800 无横向溢出，图例可见，路面控件在声场模式收起。页面异常与外网请求均为 0。截图：[平整沥青](road-smooth.png)、[粗糙沥青](road-coarse.png)、[碎石](road-gravel.png)、[原声热力图](field-primary-three-planes.png)、[残余热力图](field-residual-three-planes.png)、[窄屏](field-narrow.png)。

本批只修改 A2 viewer 与本证据，不触及 A1/B/shared/integration 源码。整个页面外层的游戏/科技风重设计、路面选择驱动真实 RNC 参数、写实车与教学声学同车配准仍未完成；不能把当前局部 HUD 认作整个平台 UI 已验收。详细版本和检查结果见根目录开发记录及草稿 PR #24。
