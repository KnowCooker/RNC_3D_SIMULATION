## 实现

- 天空由有限半径球壳改为旋转投影至无限远，不受相机平移或远裁面切割。加载时保留最后完整图，1.2 秒平滑交叉过渡；快速切换排队，旧贴图在过渡结束前不释放。经度接缝使用包裹后的显式纹理梯度，避免 mipmap 接缝闪线。
- 新远景区块 900ms 渐入，同时在 230–360m 使用径向雾渐隐；前后各约 480m 分块覆盖，在不可见范围回收。实例矩阵仅变化时上传。
- 道路地面使用世界坐标网格，避免宽地形随弯道挤压折叠。使用多尺度平滑地貌、山麓与坡向配色；水面保持水平，岸坡衔接，展厅近山后移。原有实景 8K 资源继续复用，不新增未经核对的外部图片。
- 户外相机限定平移范围、车体包络和地面高度；道路水平半径 19m，最低高度 1.1m，展厅半径 20m。树冠位于相机范围之外，叶片使用 MSAA 覆盖抗锯齿。车内固定位置视角旁路，车间保留底盘观察。

## 失败与纠正

- 首轮 TS 队列类型缩窄错误已修正；地形早期远端迭代投影出现大斜率，加入投影作用范围和步长限制后通过有界坡度检查。
- 首次浏览器脚本漏传滚轮横向参数；保留 browser-initial-script-failure.json。
- 暂停检测最初包含跳转后尚在进行的渐入；改为渐入结束后验证静止。早期天空条包含近树叶，不能归因天空闪烁，相关诊断报告和峰值实图保留；夹具位于忽略目录导致 Vite 缓存未刷新也单独保留。
- 42 项交互通过后，人工看图仍发现第 20 秒近树叶挡镜，保留 before-camera-foliage-collision.png。随后扩大树冠净空并增加实际实例检查，最终重新运行产品与逐帧验证。此失败没有被“自动测试通过”掩盖。
