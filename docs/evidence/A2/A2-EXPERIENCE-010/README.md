## 当前结果与验收界限

本批功能已实现，照片级外观最终验收**未通过**。外观仍为公开照片约束的原创曲面，不是 OEM CAD/扫描网格。前后包围、玻璃曲率、曲面过渡、局部接缝和摄影材质仍有差距；不能声称与官网照片/视频“一模一样”。需要具有相应公开交付许可的高精几何、对齐视角/光照的参考及后续逐车视觉验收，才可继续逼近该标准。没有购买或导入第三方付费模型，没有将参考照片作为贴图冒充几何。

- 五车使用各自注册的轮位、座舱、四麦克风和四扬声器坐标；切车取消旧实验、清空旧场。X9/GX 四个受控点位于前两排，第三排提供观察与真实空间查询，未增加或伪称控制通道。
- 道路以弧长驱动连续弯道/坡道，车辆位置坐标系固定，世界按车辆逆位姿运动。距离取实验播放时钟，前轮按路线曲率与轴距转向，轮胎按各自半径滚动，卡钳不随轮胎自转。前后均约480米道路，全部方向有几何与全景背景。
- 行驶中声场检视保持道路与原实验时钟；支持暂停、继续、座位位置图。体场72步声能插值叠加实际查询等值切面；检视时锁定当前窗原声/残余共同色标，读数不改变。仍为280个真实查询点的显示插值，增加渲染步数不等于提高物理解算精度。
- 程序化立体地形、湖水、岩石、山脊、雪线、枝叶、路牌、建筑和风机；展厅全周地形、道路区块可重复生成。既有8K全景与CC0岩草纹理继续复用，新增针叶/水面法线由代码生成，无新增外部图片许可。
- P7主灯腔与导光带、四车独立侧围断面/轮拱折边、X9主灯腔、X9/GX多辐轮面及五车玻璃反射调整。版本 P7 photo-v6，其余 photo-v4。拆装总成身份和声学挂点保留。
