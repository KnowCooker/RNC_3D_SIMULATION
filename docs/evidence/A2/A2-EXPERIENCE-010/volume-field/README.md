# 车内密集三维声场与行驶更新

2026-10-02 · Role: A2 · Task: A2-EXPERIENCE-010 · Identity-Source: user-declared · Executor: Codex代A2。

用户本轮要求：车内从切片为主改成三维体场，提高采样点与颜色区分度，行驶中观察RNC开关和不同路面的真实变化，并提高刷新流畅度。沿用interactive-3d-atlas技能、现有任务分支和草稿PR57。

## 当前结论

**三维呈现与密集采样已经落地；高频物理刷新仍未完成。** 当前生产引擎未获本轮B优化授权，不能把约66Hz画面调度说成每秒66次物理声场计算。B候选仅在独立试验文件中执行，未接入src/team-b或integration。

## 本轮实现

- 主体积视图移除X/Y固定平面叠层，以96步射线积分绘制三维等声压面和半透明体积。显式X/Y/Z切片仍可单独选择。
- 网格从280提高到 **13×9×17＝1989个真实B查询点，约7.1倍**；五车使用各自已有物理坐标映射。旧280点接口及其回归保持。
- 七级声压色带，固定45–85 dBA/dBZ；原声/残余及不同路面共用。改善量使用以0为中心的正负色带，真实局部变差保留。手动局部对比仍可锁定共同范围。
- 两个已计算场帧按声能进行空间和时间插值，播放时每帧更新过渡；暂停、倒放/定位、清空、变布局/计权不延续旧过渡。标注读数对应完整计算窗，插值仅用于显示。
- 每批最多192点，批间让音频/控制消息继续处理；所有分批必须属于同布局/计权/绝对时间窗才发布完整体场，变更或取消会丢弃旧结果。调度下限350→100ms，真实频率受计算耗时约束。
- 行驶检视改为斜俯视，支持旋转；修复声场页切车后停在展厅的问题，窄屏大型车相机后移以完整入画。
