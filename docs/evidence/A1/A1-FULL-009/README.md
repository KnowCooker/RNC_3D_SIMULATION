# A1-FULL-009 · 三维主舞台与路面声学联动

本批把 A2 viewer 的三种路面预设接入 A1 实验配置：平整沥青、粗糙沥青、碎石路分别写入相对粗糙度 0.6、1.2、2.2；应用初始平整路和左侧声学输入均为 0.6。切换路面会同步滑杆、取消运行中的旧 Worker、清空旧结果及声场，并要求重新计算。手动改滑杆时，界面明确指出三维材质仍显示此前选中的路面，而真实计算按手动值执行。预设是教学工况，不代表对某种实路的标定。

A1 页面使用新的本地 CSS 做三维主舞台布局、科技风控制台、声场/信号面板、试听条和窄屏控制台抽屉。控制台可收起以扩大三维视区；小屏初始收起，并可从主舞台展开。未改 A2 viewer、B 数值、shared/integration 运行源码及历史 demo-v2。

真实浏览器脚本：[qa-road-ui.playwright-cli.js](qa-road-ui.playwright-cli.js)。1600×900 的本地页面中，三种配置通过 Worker `calculate` 消息核对：粗糙沥青 1.2、碎石 2.2、手动 0.9。相同默认车速/胎面/种子下首轮源 Q1 的实际 RMS 分别为 0.9995、1.3533、0.8656，符合本教学源模型对粗糙度的趋势；这不是实车测量值。切换碎石时旧实验变为“待计算配置”、播放不可用，重新计算后能展示真实声场。控制台展开/收起、360×800 抽屉、无横向溢出、页面异常与外网请求 0 均通过。截图：[沉浸道路](immersive-road.png)、[桌面声场视口](desktop-stage.png)、[完整页声场](desktop-field.png)、[窄屏声场](narrow-field.png)、[窄屏控制台](narrow-controls.png)。

`pnpm check` 通过类型、边界、69/69 项测试和生产构建。当前写实外观与教学结构/声学点位仍未同车配准；页面视觉升级是 A1 壳层，不能代替用户要求的四车高精度三维和目标设备验收。
