## 实现范围

- 预计算回放完成后可保存当前实验的配置、runId 和 B 组分析的末尾 0.5 秒 A 计权四座读数作为基线 A。只保存小型证据快照，不复制音频数组。
- 修改配置会取消旧实验并清空旧声场/图表，基线保留；运行候选 B 后才呈现新对比。切到实时模式时基线保留但不进行实时与回放比较。
- 使用 B 组现有 `analyze` 输出原声、残余与改善；UI 仅求两次已返回指标的差值，不重算 SPL/RMS。车型、声源、种子、采样时长/末尾窗、车速、轮胎/环境和教学声压修正不同时阻止差值；多个可变项变化时明确提示不能归因。
- 来源与边界始终显示：结果是教学模型，录音作为四轮等效声源，声压为教学尺度；基线只存于当前页面内存，刷新即清除。
