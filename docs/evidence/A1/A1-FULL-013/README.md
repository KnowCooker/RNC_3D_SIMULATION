## 契约与边界

`LabConfig.layoutId` 是可省略的 `lab-v3` 字段。新默认实验写入 `teaching-fixed-v1`；旧配置省略时按同一教学布局解释。该身份对应本版本 `MIC_POSITIONS`、`SPEAKER_POSITIONS`、`SOURCE_POSITIONS` 和默认参考点，**不表示已与 Range Rover、Model Y 或其他写实资产配准**。每次预计算/实时启动前，主线程与 Worker 都检查布局身份，并把旧配置规范化为显式身份。未注册身份直接报错；无效的新请求不取消已运行的旧实验。B 组纯函数目前仍接受 `LabConfig` 并直接使用固定坐标，所以新布局启用前，B 组还须在数值入口实现同身份检查和按布局取 H/S/场点位；本批只保证正式页面/Worker 入口。

后续核查补齐了同一边界：A1 页面在清空旧实验前校验布局，`integration/main.ts` 在直接 H/S/Ŝ 路径分析前校验布局；不支持的配置不再展示固定坐标路径。路径面板对拒绝结果显示不可用并在状态栏解释原因。预计算和实时运行的三维主舞台标题也显示布局身份，避免只在案例导出时才可见。

案例 `rnc-case-v1` 格式号和原有来源边界字符串不变。导入旧文件时，缺失布局身份会被规范化为教学布局；新导出明确保存身份。A/B 身份不同或不是当前受支持布局时，比较结论不含数值差值。页面在问题卡、实验备注、自动事实和导入来源中明示布局身份及其教学限制。

### 声场帧身份贯通（2026-09-29）

正式 Worker 在预计算和实时取场时，把该实验已校验的 `layoutId` 写入 `FieldFrame`；integration 对缺失或不同于当前实验的场帧只拒绝该查询，不终止仍在运行的实验。A1 页面在送入 viewer 前再次核对场帧与当前结果配置的身份，不一致或查询失败会清除旧场，避免留下上一布局的颜色。`FieldFrame.layoutId` 暂为可选以兼容 B 纯函数的既有调用；**正式 Worker 传输必须携带**，B 纯函数的非 Worker 入口仍须在新布局开放前完成自身身份校验。A2 viewer 无需改动，当前仍只支持 `teaching-fixed-v1`。

后续把校验前移到数据入口：预计算结果的 `config.layoutId` 必须等于启动身份；实时 `ready` 回应明确携带身份；每个实时 chunk 的运行 ID、快照运行 ID 和快照布局身份都要匹配。结果/数据包错配会终止该计算线程，不让信号、试听或图表先于场帧校验接受异布局数据；场帧错配仍只拒单次场查询。正式 Worker 的 `ready` 已携带身份，不要求 B 组改变计算输出格式。伪 Worker 测试分别覆盖批量结果、实时启动确认、数据包和场帧的错配，以及仍可用的正确数据。

`pnpm check` 的类型/边界/133 项全仓测试/生产构建通过。最新真实 Chromium 在同一 BEV 默认工况下分别运行 10 秒预计算并定位末尾、实时运行约 2.2 秒，场状态为“教学布局声场截至 10.00 s / 2.03 s”，主舞台均显示 `teaching-fixed-v1`，页面脚本异常 0；[复现脚本](qa-field-layout.playwright-cli.js)、[原始结果](qa-field-layout.result.json)、[预计算整台截图](layout-field-identity-replay.png)与[实时整台截图](layout-field-identity-live.png)保存了正常结果与场帧未被误挡的证据。该检查不证明将来的写实布局已接入，也不代替目标核显、实物声音或长稳验收。

## 后续 A2/B 接入条件

### ICE 写实资产与教学坐标的定量断点（2026-09-29）

以 A2 [PR #30](https://github.com/KnowCooker/RNC_3D_SIMULATION/pull/30) 的固定提交 `d8e2717` 中 `docs/evidence/A2/A2-FULL-016/ice-layout-audit.json` 为资产几何快照，与本分支 `src/shared/lab-contracts.ts` 的教学常量按 FL/FR/RL/RR 顺序比较。欧氏距离 `√(Δx²+Δy²+Δz²)` 只用于头枕带中心对当前 MIC；轮端使用水平 `√(Δx²+Δz²)`，因为轮胎接地点不应被要求与轮心同高。

| 位置 | 当前 MIC 到该资产头枕带中心 | 当前 Q 的水平坐标到轮心 | 可核查结论 |
| --- | ---: | ---: | --- |
| FL / FR | 各 0.795 m | 各 0.196 m | 前排 MIC 尤其不能直接沿用教学位置 |
| RL / RR | 各 0.355 m | 各 0.223 m | 后排及轮端水平位置也未对齐 |

头枕带中心是资产网格区域中心，**不是**经核实的麦克风安装点；轮心也不是路噪接触源。上述距离只能证明旧坐标与该资产几何不一致，不能作为新布局建议值。旧前门扬声器坐标落在已分出的前门包围盒范围内，但没有已核实的扬声器实体/安装点；旧后门扬声器的 `z=-0.75 m` 在已分出前门的 `z≥-0.377 m` 范围外，且该资产尚无可核实的后门独立几何。A2 需继续给出四门实体和实际安装锚点，B 组在使用新布局身份前重算 R/H/S 与场；不能仅搬动三维标记。

1. A2 针对每个实际车辆资产提交稳定 `layoutId`、`assetId`、坐标原点与 X/Y/Z 方向、单位、实际车身尺寸、模型版本/哈希；四轮源、四个固定头枕误差点、四门扬声器和默认参考点各有物理坐标与安装部件 ID。位置须能在道路、车间、爆炸、剖面、复位中按同一资产核对，展示变换不改变物理坐标；不能用当前通用教学车坐标命名为新布局。
2. B 组收到已核实坐标后，以同一 `layoutId` 重算每车 H、S、参考传播与任意点声场，核查四轮/四误差点/四扬声器通道顺序及同位置同窗场值。数值入口拒绝未知布局，不因 `vehicle` 名称而默默选择固定点。
3. A1 再接入可选布局、实验身份、改制状态与案例版本；对旧案例保留教学解释，对新布局单独复验同车闭环。当前写实外观模式中的结构和声场尚未通过这一条件，不能按最终同车实验签收。
