## 实现与边界

- 三维主舞台上方新增可展开的引导控制台，保留原有手动控制。引导按真实状态要求切换预计算、计算并保存基线 A、在三维道路切换路面、重算候选 B、显示有效候选声场、同座位同起点试听 d/e，最后打开已有工程评审卡。
- 引导不生成新的噪声或收益数据；复用 `captureCase`/`compareCases` 和正式 Worker 结果。运行前用同一 A/B 比较口径检查配置，车型、车速等条件改变或多变量修改会进入修复步骤。失败/发散/无效末尾窗口、过期场或未播放的声音不推动步骤。
- 试听解锁要求用户在引导操作中从同一候选运行的左后座、同一 2.00 s 起点分别实际播放原声和残差至少 0.5 s。它只验证浏览器播放时钟与路由流程，不替代物理设备听感或音画延迟测量。
- 场只显示当前候选 B 的真实计算结果；基线 A 保留四座末尾窗口摘要，当前没有 A/B 空间差值热图。固定教学布局和非实车标定边界在控制台可见；引导完成不代表工程师已签署结论。
