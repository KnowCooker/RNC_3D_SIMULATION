## 已实现

1. **同套车型座舱**：GX/X9/L03/M03 使用带腰部收窄、肩部过渡、软垫弧度的座椅面，保留原部件 ID、装配位置和可逆拆装。局部微纹理由确定性本地材质生成，无新增外部资产。皮革采用暖浅色、低强度织物光泽；车漆保留现有颜色，调整清漆粗糙度。P7+ 原资产不替换。
2. **透明轮廓**：仅标记的照片参考模型车漆使用视角相关轮廓透明度；正视表面较透，车身边缘仍可辨认。玻璃更透明。内饰材质与实体模式隔离，释放时恢复原始所有权。不是 OEM 原生模型或实车内部标定。
3. **体声场透视**：降低显示侧光学厚度，用户不透明度在射线累积后应用，默认 75%，避免 96 次累积重新成为近不透明雾团。保留原始点序、声能插值、帧间过渡、45–85 标准色标以及有符号改善值。切片加强真实 3 dB 等值线和切面边界，不新增热点。
4. **短引线与避让**：标签靠近实际投影车辆，避让页面实测工具面板、拆装面板、模式栏和播放栏。每 200 ms 缓存更新遮挡区域。完全无可用空间时隐藏文字按钮；三维实体点与原信号选择界面仍可选择。被面板遮住的锚点不画穿板引线。
5. **路径聚焦**：默认聚焦所选通道，支持切回全部关联。只过滤渲染，所有 16 条初级与 16 条次级路径及其计算仍保留，标明“直线关系示意”；没有把直线宣称为实际车身振动传播轨迹。
