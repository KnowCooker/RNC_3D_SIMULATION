## 本批改动

- 声场页默认进入湖畔展厅，给车内空间更大的侧前三分之四观察角；道路行驶仍可在观察面板选择。手机相机按纵横比避让顶部控件，720p 主要操作和切面预览可见。
- 连续声能体场加强颜色和真实 3 dB 等值层；实际座椅/底盘深度遮挡后方场，透明外壳保留源几何轮廓。保留原有帧间声能插值，不制造热点或修改数值。光线步进从 96 降为 72，去掉每步额外梯度纹理读取；新增不透明车体深度预绘制，未声称实际设备帧率提升幅度。
- 同座同窗 d/e/改善读数卡；原声/残余共用 45–85 dB(A) 色标，改善默认 −10～+10 dB，真实负值保留。超出色标的数据仍由原有数值/空间证据显示，不等同于截断计算值。
- 水平/纵向/横向切面来自当前车型、当前空间帧、相同计权和色标；双画布交叉淡化，并在页面隐藏时停止刷新。缩略图显示自己的空间采样时间；实时麦克风分析可能领先异步空间帧，不宣称二者始终同时到达。
- 四座测点、计权和显示细节按需展开。清旧时同时清理读数、主场、色标及预览。
