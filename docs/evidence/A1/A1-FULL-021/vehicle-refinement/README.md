## 实际变化

- 共用 PBR 车漆：金属底漆、清漆层、细微粗糙度；展厅宽面柔光形成连续高光，微细接缝不再投射噪点阴影。车窗视角相关透明覆盖，近正视更清晰，掠射角反射保留。是薄片覆盖近似，不是光追折射。
- 座舱：曲面软包仪表台、打孔皮革座椅、贴合曲面的细走线、座椅背壳与置物口、窄木饰条、金属把手/按键、地毯与脚垫、低亮暖色灯带。屏幕纹理是装饰，不是实验仪表或实时数据。全部纹理由本地程序生成并使用 mip 过滤，不引入外部图片许可。
- 小鹏系列及 MONA 共用材质；P7+ 座椅同步连续软包曲面。新增细节跟随对应车门/座椅/地板/仪表台拆装，不改车身外包络、物理锚点或硬件数量。
- 仅在同一个可拆总成、同材质/壳体归属/可见性/投影设置内合批匿名静态网格；命名硬件、子层级和卡钳保留。复用几何并减少微小倒角过密分段；缓存车轮节点；同检视状态不反复使材质程序失效；轨道阻尼按帧间隔调整。
