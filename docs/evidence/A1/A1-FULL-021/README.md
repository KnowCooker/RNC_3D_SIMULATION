## 保留的视觉与工程差距

- 当前车型是仓库现有照片参考重建，外壳曲面、内饰和透明轮廓仍达不到母版中的精细写实SUV；本轮不冒称逐像素或资产级复刻。A2后续应升级同一可拆解SUV资产，A1首页会直接复用。
- 美术湖景是艺术远景，侧后方继续过渡到摄影全景；没有声称完整同址世界或无缝标定。母版近景陈设和更精细建筑材质尚非完全一致。
- 热图颜色按真实模拟值映射，不为获得母版彩虹效果而捏造分布。未测第二机/核显稳定帧率或长时间显存峰值。场查询与最新到帧频率未提升，前一任务的连续过渡保留。
- 预览只改变展示，不修改物理坐标、仿真算法或道路功能。需待父PR和B2兼容阻塞处理后再集成main。
