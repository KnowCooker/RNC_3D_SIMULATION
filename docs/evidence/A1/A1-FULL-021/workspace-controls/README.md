## 已实现的交互

| 用户任务 | 页面行为 |
| --- | --- |
| 选择展厅或道路 | 声场/结构工作页下方常驻两个主按钮；金色标记当前模式，保留独立“行驶声场”入口。点击从结构进入声场实验，复用原车辆、播放器和实验。 |
| 进入道路后换环境 | 主视图区显示四张环境选择卡：田野公路、山地、沙漠、雪山，显示选中项及加载/失败状态；与总览的环境选择同步。田野缩略图复用实际道路全景。 |
| 控制道路观察 | “道路行驶”同时切到右栏行驶观察选项；“展厅声场”和“行驶声场”切回声场与读数。环境只影响景物，工况/路面粗糙度仍通过原设置修改并使旧结果失效。 |
| 给三维主体腾出空间 | 声场右栏、结构右栏与底部结构工具各自可展开/收起；保留控件实例与选中状态，页面往返不重建。支持按钮键盘操作和正文内 Escape 收起，焦点返回展开按钮。 |
| 查看 A/B 为什么不同 | 先显示实际变更的配置项及其 A/B 值，再显示四测点残余声压、降噪量共轴图，以及 B−A 降噪量变化。相同条件、原始数值和实验身份可展开。 |
| 处理无效对比 | 没有两次独立实验时显示步骤，不使用示例数字。控制工况不一致时仅并列原值，隐藏图形连线和差值；多变量和场景比较明确限制归因。缺失读数保持缺失，负收益明确显示。 |
| 复核导入记录 | 使用同一套图表，明确标注“文件自报、未在本机重算”，不修改当前实验；不支持的布局仍阻止差值。 |

额外修复：结构“编辑声学硬件”直接进入正确设置分类；收起声场面板停止其额外三维缩略预览绘制；桌面按播放器/底部控件实际高度预留空间，移动端固定主要场景按钮。新监听、观察器与动画帧均随 shell 销毁释放。

## 数据边界

- 图表只读取既有 `CaseSnapshot` 和 `compareCases` 的结果，不新增 SPL/RMS/降噪计算。原声/残余为 dBA，降噪量/差值为 dB；仍是末尾 0.5 秒、A 计权、0–1 kHz 教学模型。
- 两个方案共享图内坐标轴。采用点线图表达声压，避免截断分贝柱状图夸大差异；改善条以零点为中心，保留正负号和文字，不仅用颜色判断好坏。
- “显示精度内相同”仅表示 0.1 dB 展示精度，不是统计显著性或工程合格性结论。没有自动给出“最佳方案”。
- 当前摘要没有保存两次频谱，故不伪造 A/B 频谱、收敛曲线或持续时域结果。

## 验证与限制

新增 13 项专项：真实配置/数据映射、共享坐标、负收益、缺失/非有限值、未知布局/时间窗、控制不可比、场景归因、多变量、导入文本转义及不可变快照；DOM 测试替身验证保留控件、独立面板状态、Escape/焦点、监听释放。测试替身不是完整浏览器。

### 页面人工验收脚本

在 1920×1080、1280×720、390×844 分别检查：

1. 声场实验 → 下方“道路行驶”：道路与环境卡出现，当前状态一致；切四环境，加载/失败提示可理解，原实验结果不因单纯景物变化而变动。
2. “行驶声场” → “展厅声场” → “道路行驶”反复切换；声场量、行驶观察面板与下方选中状态一致，计算/暂停/播放仍可使用。
3. 右侧声场面板收起 → 展开；已选切面/计权/座位不重置。折叠时外部场景和下方控件可用。键盘 Tab 可定位展开按钮，正文 Escape 后焦点可见。
4. 结构与布置页：收起右栏与底部工具栏，分别展开；拆解、回装、外壳、安装点均保留。点击“编辑声学硬件”打开控制与硬件分类。
5. 比较页首次无记录：仅显示建立 A/B 的引导。计算保存 A，修改一个控制参数，再计算 B：核对配置表和两幅四测点图对应 JSON/原始表值。
6. 候选修改车速：控制比较不显示差值；改为场景结果并列后显示差异但不声称 ANC 净收益。修改后尚未重算时旧候选图必须消失。清除 A 同样清图。
7. 导出再导入记录：导入图标明文件自报且不覆盖当前实验。未知布局、坏文件、无读数维持原防护。
8. 720p 不应出现底部按钮遮住滚动面板尾部；手机主要按钮在可触及位置、无横向整页溢出；对比图四测点名称和数字可读。观察低性能设备连续 2 分钟道路+声场+乘客场景，记录帧耗时和内存，不能以构建通过代替此项。
