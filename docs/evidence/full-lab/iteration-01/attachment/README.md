# 附着一致性浏览器验证

在仓库根目录启动 Vite（本次地址 http://127.0.0.1:5177/），用 Playwright CLI 新建专属会话，窗口设 1500×1100。依次执行 setup.js、读取 snapshot、checks.js、mount-checks.js。结果保存在 *-result.json；不要在已有 mount-checks 状态再次跑完整检查，先重新执行 setup。

这是独立真实 WebGL viewer 测试：setup 在专属浏览器页面创建另一个 viewer，并临时截取该实例 render 的 scene/camera，随后还原 prototype。未向产品暴露测试API，未修改产品计算结果。

checks 使用明确注入的常值声场夹具（60/50 dB）和驱动1，专门验证空间体/波前的显示附着，不能作为声学公式/降噪效果证据。

实际通过：
- Q1–Q4按钮返回 q/0–3；Q4被选中时高亮。
- 爆炸过程中4个OUT与实体扬声器中心、4个MIC与座舱、4个Q与轮组、1个roof附着参考一致。
- 32条初/次级线路两端与对应标记一致；32个移动光点始终在线段上。
- 12个波前中心对应实体扬声器；停用FR后其3波前及4次级线路/光点隐藏。
- 空间体随座舱上移.45×progress，实体模式6玻璃面保留.28透明度。
- 真实鼠标点击已展开车顶，回调保存未展开物理位置和mountPart=roof；重建/收拢后该参考仍附着车顶，config物理坐标不被修改。
- 隐藏外壳、完全剖去的面、不可见祖先下的面不能被新增传感器命中。
