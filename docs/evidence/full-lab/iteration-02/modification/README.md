## 观察方式与复现

按顺序使用 Playwright CLI `run-code --filename` 执行本目录 `install.js`、`four-cars.js`、`speakers.js`、`charge.js`、`combinations.js`、`export.js`。

`install.js` 添加只读观察器：Worker 的原生 `postMessage` 原样透传，原生 message 事件记录真实配置与返回结果；在应用入口前给实际 Three.js renderer 加一个透传观察器，只保存 scene/camera 用来计算可见表面的屏幕位置。没有替换 Worker、物理算法、控制输出、随机源或声场结果，也没有另行挂载测试 viewer。

车型、车身、剖面、爆炸、扬声器、改制、计算均通过页面实际表单或鼠标操作。新增参考由 `page.mouse.click` 点击 canvas 的可见表面完成；投影与射线只用于预先寻找合法屏幕坐标，不直接调用 `addReference` 或修改配置。删除通过真实标记右键菜单完成。计算和信号观察来自完整应用自己的真实 Worker。

初始化首次未匹配带 `?t=` 的 Vite 入口 URL，观察器等待超时；将路由匹配改为 `main.ts*` 后重新加载成功。这是验证脚本问题，非应用故障。原始汇总见 `result.json`，精简结果见 `summary.json`，导出工具原文见 `export-transcript.txt`。

## 实测结果

- 四车型均添加第 5 个参考，实际 Worker 请求和返回都带相同 `position`、`mountPart`、车型，返回 5 路真实 x；第 5 路信号峰值非零。三维点选择 REF 后框图与信号标题一致，框图 Q3 反向选中三维 Q3。
- 四车型都在完全爆炸状态点击：ICE 为 `roof`，其余为 `cockpit`。存入 Worker 的是未展开物理位置；与点击世界坐标减安装件位移之差最大 9.57e-7 m。ICE `roof` 分组包含车顶支柱等外壳面，此次实际点击该组的可见支柱面，并非宣称点击了车顶最高面。
- 四车型分别右键删除刚添加的参考，页面和框图回到 4 路并要求重算。误差点右键菜单只有“查看信号与频谱”，没有删除入口。
