## 1. 信号如何生成

采样率 2000 Hz，预计算时长可选整数秒（默认16秒，默认4参考上限112秒）；实时模式持续生成新样本并保留滤波器状态，不循环播放前16秒。

现采用用户提供的纯电车、40 km/h、粗糙路录音的归一化谱形。录音为4000 Hz、40秒、48路参考+8路双耳噪声，全部未经校准、单位V。仅以MATLAB提取格式元信息，不执行其控制/预处理/通道置零/校准公式。

四个轮端各产生等效振动激励 q，单位仍为教学等效m/s²，并非将实录V换算为m/s²。固定种子的伪随机均匀噪声（seed + 101×轮端索引）经255系数最小相位FIR整形；根据48路参考逐路归一化后的中位谱及本工程参考传播响应拟合，默认谱形保留较宽频带。四轮使用不同伪随机序列，不重放录音，也不复现实录通道间相位/相干关系。旧97系数固定带通及95/220 Hz纯音已撤出lab-v3；demo-v2保持冻结。

```text
q_i[n] = A × (整形FIR * 独立伪随机激励_i)[n]
A = (车速/40)^1.25 × sqrt(路面粗糙度)
    × (0.65 + 0.35×胎面粗糙度) × 10^[-0.04(温度-20)/20]
谱形伸缩 = sqrt(胎压/240) × sqrt((温度+273.15)/293.15)
```

粗糙度1表示实录粗糙路的相对基准。运行默认速度仍为60 km/h；选择40 km/h对应录音基准。温度增益、胎压/温度伸缩及速度指数仍是教学外推，不可能仅凭单一工况辨识这些规律。通过对FIR系数时间轴线性重采样并保持单位激励RMS实现谱形伸缩。同参数、同种子可复现。车速为0时源为0；未单独分离录音中的发动机/电机/风噪成分，也未新增独立噪声源。当前车速只影响幅值，不模拟随速度移动的空间路谱/轮胎阶次，也未模拟前后轮驶过同一段路面的精确时差。详见[实录数据分析与验证](../evidence/B/B1-DATA-001/README.md)。

## 2. 三类路径与控制关系

星号表示时域卷积，各式对所有输入通道求和：

```text
参考信号：x_k = Σ R_ki * q_i
原始声压：d_m = Σ H_mi * q_i
扬声器驱动：u_j = Σ W_jk * x_k
次级声压：a_m = Σ S_mj * u_j
残余声压：e_m = d_m + a_m
```

**参考路径 R（轮端→振动传感器）**：距离 r 决定延时 r/900 秒和耦合增益 exp(-r²/2.5)/(0.35+r)，再经过 [0.85, 0.15] 整形。900 m/s 是有效结构传播速度的教学设定。移动参考改变 x 的延时、幅值和与噪声的相关性，不直接改变原声 d。

**初级路径 H（轮端→车身/地板辐射→座位）**：先将轮端映射至地板辐射点 [0.72×轮端x, 0.58, 0.85×轮端z]，加入车型结构延时，再计算到目标点的直达声、地板与车顶的两条镜像反射。基础增益为0.065×车型初级系数，末端整形 [0.72, 0.28]。

在上述几何路径上再卷积一个129系数的共同因果整形FIR，使默认BEV四点合成原声的平均归一化谱形接近实录8路耳旁V²/Hz平均谱。它是教学谱形修正，不是由x/d辨识的真实H；未拟合实测相位、因果预测能力或各座位实测电压差异。最终H再乘教学声压增益3.45999433及10^(声压修正dB/20)，详见第6节。任意空间点同样从q经过此路径计算，不插值四点场值。流式路径前史增至256采样（含A计权所需前史），源历史环为512采样。

**次级路径 S（扬声器→座位）**：扬声器固定物理坐标出发，同样采用直达＋两次早期反射；基础增益0.28，附加延时1个采样（0.5 ms），整形 [0.18, 0.32, 0.32, 0.18]。四个扬声器都影响四个座位，保留全部16条次级路径及交叉耦合。

用户提供的secpath.dat为8头枕扬声器×8耳旁误差点×256采样，与本模型4车门扬声器的拓扑不同；按用户回复不接入，仅分析归档其尺寸/谱形。S及NFxLMS更新公式不受外来MATLAB控制代码影响。

H/S每条分量的幅值按1/(0.4+r)衰减，传播延时为 r/c，c=331.3×sqrt((T+273.15)/273.15) m/s。直达/地板/车顶相对系数为1、车型反射系数、0.6×车型反射系数。地板镜像面为y=0.55 m，车顶镜像面为车型roof。分数采样延时线性分配到相邻采样点，得到稀疏因果FIR；并非随机生成路径，也不是从3D网格做声线追踪或有限元求解。

W通过归一化多通道NFxLMS学习；目前采用理想的次级路径估计 S_hat=S，没有加入辨识误差。默认从0秒学习，初始权重为0，当前误差只更新下一样本的权重。关闭算法、μ=0或禁用全部输出时 u=a=0，e=d。空间声场也使用上述q/u与路径逐点计算，不从四个座位插值出假声场。

归一化形式如下，j为扬声器、k为参考、m为误差点，向量包含当前及前L−1个样本：

```text
xf_mjk = S_hat_mj * x_k
E = 1e-6 + Σ_mjk ||xf_mjk||²
W_jk[n+1] = W_jk[n] − (μ/E) × Σ_m e_m[n] xf_mjk[n]
```

此前lab实现已具有上述联合能量归一化。本批把批量和流式的归一化计算抽为同一函数，统一命名为NFxLMS并补测试；没有用改名称冒充新的降噪收益。A计权只在分析端，不加入控制目标；控制仍最小化线性误差能量。

## 3. 参数影响

| 参数 | 当前实际影响 |
| --- | --- |
| 车速 | 激励幅值按v^1.25变化；不直接改路径或移动谱峰 |
| 路面粗糙度 | 激励幅值乘其平方根；不直接改路径 |
| 胎面粗糙度 | 激励幅值乘0.65+0.35×该值；不直接改路径 |
| 胎压 | 伸缩整个源谱形；没有直接幅值系数，也不改H/S |
| 温度 | 改激励幅值及谱形，并通过声速改变H/S传播延时；不改R |
| 车型 | 不直接改变q；改变H/S的车型参数，见下表；当前R无车型参数 |
| 参考数量/位置 | 改R、参考x及控制器维度/输入信息；不直接改变d |
| 扬声器启禁 | 改可用控制输出及残余声；不改变原声 |
| NFxLMS系数数/步长 | 改控制器表达能力、学习速度与稳定性；不改q及物理H/S |
| 教学声压修正 | 仅对H增加−12～+12 dB，q/x/S不变；d改变后u/e随控制计算响应 |
| 计权/频谱显示范围 | 只改变分析展示；不改变原始样本、学习、播放位置或试听 |
| 仿真时长 | 改计算样本数和播放终点；不改变相同时间内的源及算法；实时模式持续运行 |
| 图表/试听座位 | 选择对应通道展示、试听；不重算也不重置学习 |
| 底部RNC ON/音量/静音 | 仅控制试听，图表保留原声/残余对照；左侧“启用RNC”才改变计算配置 |

物理参数或改制变化会要求重新启动实验，学习状态重置；当前不模拟运行中连续变化的车舱路径。

新低频谱形下μ=0.5的高能量/参考重合工况会触发原有数值发散保护；默认μ=0.08验证通过。这是更新数据后的已知运行边界，不限幅u、不调整梯度公式、不伪造收益。

## 5. 图表口径

每类图只有一张，底部“座位（图表 / 试听）”统一选FL/FR/RL/RR；选择座位返回该座位的d/e对照。右击硬件或点击框图仍可临时查看q/x/u/a等信号，再选座位即可返回声压对比。RNC ON仅切换听到的声音。

时域横轴为实验秒数、声压单位Pa，保留未计权波形。频域为Hann 1024点单边PSD，默认A计权，也可选线性Z；默认横轴20～500Hz，可在0～1000Hz内调整。PSD是每Hz的功率谱密度，不是每个频点的总声压级；A谱用线性PSD乘A曲线幅值平方。振动q/x及驱动u保持其物理线性单位，原声对照独立按所选声压计权显示。

收敛图、四座位指标和空间声场默认dBA，可统一切至线性dB。总级为0.5秒窗口10log10(mean(p_w²)/(20µPa)²)，p_w为A滤波后信号或原始Z信号。**统计完整0～1kHz计算频带，不受频谱横轴截取影响**；不代表完整可听频带的车内总噪声。首个有效点0.5秒，学习本身从0秒开始。实时曲线截止播放时钟，保留最近120秒；A/Z历史同时保存，切换不会丢失历史。

A时域滤波使用2kHz下65系数最小相位FIR，带有64点前史；校验频点20～1000Hz最大响应偏差约0.103dB。有限FIR在极低频并非理想连续曲线，不宣称符合声级计认证或IEC完整频带公差。A权重形式参考[MathWorks音频计权说明](https://www.mathworks.com/help/audio/ug/audio-weighting-filters.html)，没有引入用户MATLAB程序的处理。计权不影响RNC ON试听信号、公共试听安全增益或物理计算结果。

## 6. 教学声压幅度校准

实录全部为未经校准的V，不能恢复实际Pa或实测dBA。选择**BEV、40km/h、粗糙度1、胎面1、240kPa、20°C、seed11、默认坐标、16秒实验末4秒、四座位能量平均的原声60dBA**作为可调教学锚点，而非声称该车录音就是60dBA。

校准脚本先算上述工况未缩放A计权功率，再求全局压力增益10^((60−49.21849226)/20)=3.45999433，固定应用于所有H。此增益不随本次时长、座位或RNC开关重新标定，因此参数趋势和相对降噪仍来自真实计算。新增声压修正−12～+12dB；例如+6dB将d的压力幅值约乘2，x保持不变。

公开车辆测量显示声级会随路面、速度、车辆和测量口径大幅变化（[实测研究](https://www.mdpi.com/2076-3417/16/2/580)、[SAE车内噪声测量规程](https://saemobilus.sae.org/standards/j1477_202410-measurement-interior-sound-levels-light-vehicles)）。60dBA是参考一般量级后为本软件选定的教学值，资料未标定这份数据。本模型保留强低频实录形状，线性dB可显著高于dBA；没有把谱形改变成便于展示的虚假平坦谱，也不额外伪造真实车辆全频噪声。

## 7. 时长与性能边界

批量时长为整数秒，默认16秒。上限依据256MiB工作预算估算，包含worker数组、传输/播放副本、A计权缓存和8路16kHz试听PCM缓存，并设置300秒硬上限。当前64系数下：1参考186秒、4参考112秒、8参考73秒；系数数也参与预算。不是自动探测浏览器可用RAM，也不是全设备性能保证。

本机Node验证112秒默认实验：核心计算约1.90秒、A/Z收敛历史约0.16秒、试听准备加单路重采样约0.12秒。浏览器42秒实验完成、可定位42秒末端。实时模式保留有界信号历史并连续学习，无固定结束时间，性能仍依设备和场景复杂度而异。

源使用实录统计谱驱动的连续随机合成，所以超过原始40秒无需复制录音，不会在循环边界重复/重置滤波器。仍不复现实录通道相干性，S_hat=S为理想估计，不能将仿真降噪量当作实车试验结论。
