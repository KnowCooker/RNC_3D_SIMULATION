## 1. 信号如何生成

采样率2000 Hz，界面默认实时连续仿真，等待用户点击启动；预计算可选10～90秒、默认20秒。实时持续处理并保留权重/路径状态，内部600秒上限。低层历史配置省略sourceMode时仍保持原随机模式；界面明确传入recorded-noise作为默认。

用户提供的纯电车、40 km/h、粗糙路录音为4000 Hz、40秒、48路参考+8路双耳初级噪声，全部未经校准、单位V。仅以MATLAB提取格式元信息，不执行其控制/预处理/通道置零/校准公式。

**默认：实录初级噪声声源。** 选取FL/FR/RL/RR各左耳的原始初级噪声，物理通道49/53/51/55，按此顺序放置在四轮位置。不使用1～48路振动，也不把双耳波形平均。四路先去直流、经同一257系数Kaiser低通（900Hz截止、1kHz以上最大约−94.9dB）抗混叠后降采样到2kHz，使用一个共同RMS缩放，保留相对幅度与同步关系。q在此模式标为相对幅值，不能视为实测Pa或m/s²。

40秒四路素材约1.28MB，作为固定输入资源加载；不保存600秒输出波形。所有通道按同一时钟、同一0.2秒升余弦权重交叠首尾，循环周期39.8秒。中间样本直接来自录音，不随机化相位、不重新整形；首尾交叠区是平滑混合。控制器、传播历史和样本计数不在循环处重置。普通速度/粗糙度/胎面/温度幅度外推仍可用；保留录音原频率，胎压谱形外推在此模式禁用。

**可选：随机噪声经实录谱形整形。** 以下旧源公式及其胎压/温度谱形伸缩仅适用于shaped-noise模式：

四个轮端各产生等效振动激励 q，单位仍为教学等效m/s²，并非将实录V换算为m/s²。固定种子的伪随机均匀噪声（seed + 101×轮端索引）经255系数最小相位FIR整形；根据48路参考逐路归一化后的中位谱及本工程参考传播响应拟合，默认谱形保留较宽频带。四轮使用不同伪随机序列，不重放录音，也不复现实录通道间相位/相干关系。旧97系数固定带通及95/220 Hz纯音已撤出lab-v3；demo-v2保持冻结。

```text
q_i[n] = A × (整形FIR * 独立伪随机激励_i)[n]
A = (车速/40)^1.25 × sqrt(路面粗糙度)
    × (0.65 + 0.35×胎面粗糙度) × 10^[-0.04(温度-20)/20]
谱形伸缩 = sqrt(胎压/240) × sqrt((温度+273.15)/293.15)
```

粗糙度1表示实录粗糙路的相对基准。运行默认速度仍为60 km/h；选择40 km/h对应录音基准。温度增益、胎压/温度伸缩及速度指数仍是教学外推，不可能仅凭单一工况辨识这些规律。通过对FIR系数时间轴线性重采样并保持单位激励RMS实现谱形伸缩。同参数、同种子可复现。车速为0时源为0；未单独分离录音中的发动机/电机/风噪成分，也未新增独立噪声源。当前车速只影响幅值，不模拟随速度移动的空间路谱/轮胎阶次，也未模拟前后轮驶过同一段路面的精确时差。详见[实录数据分析与验证](../evidence/B/B1-DATA-001/README.md)。

## 2. 三类路径与控制关系

星号表示时域卷积，各式对所有输入通道求和：

```text
参考信号：x_k = Σ R_ki * q_i
原始声压：d_m = Σ H_mi * q_i
扬声器驱动：u_j = Σ W_jk * x_k
次级声压：a_m = Σ S_mj * u_j
残余声压：e_m = d_m + a_m
```

**参考路径 R（轮端→振动传感器）**：距离 r 决定延时 r/900 秒和耦合增益 exp(-r²/2.5)/(0.35+r)，再经过 [0.85, 0.15] 整形。900 m/s 是有效结构传播速度的教学设定。移动参考改变 x 的延时、幅值和与噪声的相关性，不直接改变原声 d。

**初级路径 H（轮端→车身/地板辐射→座位）**：先将轮端映射至地板辐射点 [0.72×轮端x, 0.58, 0.85×轮端z]，加入车型结构延时，再计算到目标点的直达声、地板与车顶的两条镜像反射。基础增益为0.065×车型初级系数，末端整形 [0.72, 0.28]。

实录噪声模式采用另一条等效H：保留相同辐射点、声速、距离衰减与两条早期反射，但不使用上述[0.72,0.28]滤波及下面129系数振动转噪声整形，避免二次染色。分数延时采用17点Blackman窗sinc，附加8个因果样本延时，减少两点插值的高频衰减。每路源的空间耦合乘以`0.05 + 0.95 exp(−[(x−x_seat)/0.4]²−[(z−z_seat)/0.6]²)`，seat为对应固定麦克风点。对应座位由该源主导，其他源仍非零耦合；任意空间点均直接从q/u逐路径计算，不插值四座SPL。这是为保留录音各座位特征构造的教学等效耦合，不是实测声辐射指向性，也不是从耳旁录音唯一反演出的真实轮胎声源。

单一40km/h素材、默认几何下，1～900Hz七频带的逐座位归一化功率平均绝对误差为0.525/0.714/0.513/0.623dB，旧随机模式相对于同四路目标为4.028/1.435/1.532/4.180dB；合并误差0.430dB对1.126dB。比较使用同一独立Welch口径，并非新的实车验证或原波形逐样本重现。详见[LIVE-003频谱对照](../evidence/B/B1-LIVE-003/spectral-comparison.json)。

在上述几何路径上再卷积一个129系数的共同因果整形FIR，使默认BEV四点合成原声的平均归一化谱形接近实录8路耳旁V²/Hz平均谱。它是教学谱形修正，不是由x/d辨识的真实H；未拟合实测相位、因果预测能力或各座位实测电压差异。最终H再乘教学声压增益3.45999433及10^(声压修正dB/20)，详见第6节。任意空间点同样从q经过此路径计算，不插值四点场值。流式路径前史增至256采样（含A计权所需前史），源历史环为512采样。

**次级路径 S（扬声器→座位）**：扬声器固定物理坐标出发，同样采用直达＋两次早期反射；基础增益0.28，附加延时1个采样（0.5 ms），整形 [0.18, 0.32, 0.32, 0.18]。四个扬声器都影响四个座位，保留全部16条次级路径及交叉耦合。

用户提供的secpath.dat为8头枕扬声器×8耳旁误差点×256采样，与本模型4车门扬声器的拓扑不同；按用户回复不接入，仅分析归档其尺寸/谱形。S及NFxLMS更新公式不受外来MATLAB控制代码影响。

H/S每条分量的幅值按1/(0.4+r)衰减，传播延时为 r/c，c=331.3×sqrt((T+273.15)/273.15) m/s。直达/地板/车顶相对系数为1、车型反射系数、0.6×车型反射系数。地板镜像面为y=0.55 m，车顶镜像面为车型roof。分数采样延时线性分配到相邻采样点，得到稀疏因果FIR；并非随机生成路径，也不是从3D网格做声线追踪或有限元求解。

W通过归一化多通道NFxLMS学习；目前采用理想的次级路径估计 S_hat=S，没有加入辨识误差。默认从0秒学习，初始权重为0，当前误差只更新下一样本的权重。从启动即关闭算法、μ=0或禁用全部输出时 u=a=0，e=d。实时运行中切到RNC OFF时冻结W、令新生成的u为零，已进入S的输出历史继续因果传播；短暂余响消退后a=0、e=d。OFF期间源、参考、filtered-x与归一化能量继续更新，重新ON沿用冻结权重和当前输入恢复学习。空间声场也使用上述q/u与路径逐点计算，不从四个座位插值出假声场。

归一化形式如下，j为扬声器、k为参考、m为误差点，向量包含当前及前L−1个样本：

```text
xf_mjk = S_hat_mj * x_k
E = 1e-6 + Σ_mjk ||xf_mjk||²
W_jk[n+1] = W_jk[n] − (μ/E) × Σ_m e_m[n] xf_mjk[n]
```

此前lab实现已具有上述联合能量归一化。本批把批量和流式的归一化计算抽为同一函数，统一命名为NFxLMS并补测试；没有用改名称冒充新的降噪收益。A计权只在分析端，不加入控制目标；控制仍最小化线性误差能量。

## 3. 参数影响

| 参数 | 当前实际影响 |
| --- | --- |
| 车速 | 激励幅值按v^1.25变化；不直接改路径或移动谱峰 |

| 胎压 | 随机模式伸缩源谱形；实录模式禁用，不改变录音频率 |

| 车型 | 不直接改变q；改变H/S的车型参数，见下表；当前R无车型参数 |
| 参考数量/位置 | 改R、参考x及控制器维度/输入信息；不直接改变d |
| 扬声器启禁 | 改可用控制输出及残余声；不改变原声 |
| NFxLMS系数数/步长 | 改控制器表达能力、学习速度与稳定性；不改q及物理H/S |
| 教学声压修正 | 仅对H增加−12～+12 dB，q/x/S不变；d改变后u/e随控制计算响应 |
| 计权/频谱显示范围 | 只改变分析展示；不改变原始样本、学习、播放位置或试听 |
| 仿真时长 | 改计算样本数和播放终点；不改变相同时间内的源及算法；实时模式持续运行 |
| 图表/试听座位 | 选择对应通道展示、试听；不重算也不重置学习 |
| 底部RNC ON/OFF | 回放切换已计算的e/d试听；实时始终听e，开关直接控制W更新及u输出，不重启源、时钟或学习 |

新低频谱形下μ=0.5的高能量/参考重合工况会触发原有数值发散保护；默认μ=0.08验证通过。这是更新数据后的已知运行边界，不限幅u、不调整梯度公式、不伪造收益。

## 5. 图表口径

每类图只有一张，三张卡片与绘图区等尺寸，宽屏三列、窄屏单列。底部“座位（图表 / 试听）”统一选FL/FR/RL/RR；选择座位返回该座位的d/e对照。右击硬件或点击框图仍可临时查看q/x/u/a等信号，再选座位即可返回声压对比。实时无论查看哪个信号都试听所选座位e，回放RNC ON/OFF只选择固定e/d。

时域横轴为实验秒数、声压单位Pa，保留未计权波形。窗口长度5秒：开始时固定0～5秒，超过5秒后显示试听时刻之前的最近5秒。频域继续采用Hann 1024点单边PSD，默认A计权，也可选线性Z；默认横轴20～500Hz，可在0～1000Hz内调整。PSD是每Hz的功率谱密度，不是每个频点的总声压级；A谱用线性PSD乘A曲线幅值平方。振动q/x及驱动u保持其物理线性单位，原声对照独立按所选声压计权显示。

收敛图、四座位指标和空间声场默认dBA，可统一切至线性dB。总级为0.5秒窗口10log10(mean(p_w²)/(20µPa)²)，p_w为A滤波后信号或原始Z信号。**统计完整0～1kHz计算频带，不受频谱横轴截取影响**；不代表完整可听频带的车内总噪声。首个有效点0.5秒，学习本身从0秒开始。实时曲线截止播放时钟，保留本次实验全程的总声压级标量（最多约10次/秒），不保留全程波形；四座A/Z历史同时保存，切换不会丢失历史。

A时域滤波使用2kHz下65系数最小相位FIR，带有64点前史；校验频点20～1000Hz最大响应偏差约0.103dB。有限FIR在极低频并非理想连续曲线，不宣称符合声级计认证或IEC完整频带公差。A权重形式参考[MathWorks音频计权说明](https://www.mathworks.com/help/audio/ug/audio-weighting-filters.html)，没有引入用户MATLAB程序的处理。计权不影响RNC ON试听信号、公共试听安全增益或物理计算结果。

## 6. 教学声压幅度校准

实录全部为未经校准的V，不能恢复实际Pa或实测dBA。选择**BEV、40km/h、粗糙度1、胎面1、240kPa、20°C、seed11、默认坐标、16秒实验末4秒、四座位能量平均的原声60dBA**作为可调教学锚点，而非声称该车录音就是60dBA。

校准脚本先算上述工况未缩放A计权功率，再求全局压力增益10^((60−49.21849226)/20)=3.45999433，固定应用于所有H。此增益不随本次时长、座位或RNC开关重新标定，因此参数趋势和相对降噪仍来自真实计算。新增声压修正−12～+12dB；例如+6dB将d的压力幅值约乘2，x保持不变。

以上3.45999433继续适用于旧随机模式。实录噪声模式按同一60dBA教学目标，用40km/h默认BEV、1～39秒四座A功率平均确定固定H增益4.3619057736237865；与本次RNC输出、座位选择和运行时长无关。共同录音归一化及该教学增益均不是传感器V/Pa校准。

公开车辆测量显示声级会随路面、速度、车辆和测量口径大幅变化（[实测研究](https://www.mdpi.com/2076-3417/16/2/580)、[SAE车内噪声测量规程](https://saemobilus.sae.org/standards/j1477_202410-measurement-interior-sound-levels-light-vehicles)）。60dBA是参考一般量级后为本软件选定的教学值，资料未标定这份数据。本模型保留强低频实录形状，线性dB可显著高于dBA；没有把谱形改变成便于展示的虚假平坦谱，也不额外伪造真实车辆全频噪声。

## 7. 时长与性能边界

界面预计算时长仅可选10、20、…、90秒，默认20秒；车速入口为10～130 km/h。底层批量接口保留历史整数秒和停车零能量验证能力。上限继续依据256MiB工作预算估算，包含worker数组、传输/播放副本、A计权缓存和8路16kHz试听PCM缓存。当前64系数下8参考预算为73秒，界面仅启用至70秒，80/90秒禁用；增加参考导致超预算时自动落到最高可用档。不是自动探测浏览器可用RAM，也不是全设备性能保证。

此前B1-ANALYSIS-001的112秒核心性能与42秒浏览器证据仅是旧版历史验证。当前实时模式不读取预计算时长来分配全程数组，也不校验预计算内存预算。Worker循环缓存及图表快照上限均为16384点（8.192秒），为5秒波形、试听预取及因果前史留出空间；试听预取目标1.2秒，播放器拒绝超过2秒队列。频谱和场值按试听时刻取最近窗口。

实时底部只显示累计mm:ss.xx计时，不显示可定位进度条；预计算显示已播放/总时长及进度条。实时开关命令返回首个生效样本序号，界面以实际试听时钟确认生效。已有约1.2～1.4秒声音预取队列不回滚、不重算，按钮先显示请求的ON/OFF，状态提示正在切换，到达生效点再更新控制示意。待生效期间禁用重复切换；暂停时切换会等待恢复播放到该点。

实时处理器按需生成新随机样本，保留有限的随机数发生器状态、源谱整形FIR/传播延时、filtered-x历史、权重及归一化能量；这些状态保证跨块连续和持续自适应。它不需要保存所有过去的信号，也不能在每块重置状态。算法持续更新并不保证误差始终单调下降或任意步长稳定。

内部运行上限为累计600秒仿真样本时间，不提供用户设置；暂停/后台暂停不消耗该额度。到达上限后不再计算新块，播放器补齐末端24ms重采样前瞻并淡出，准确在600秒结束，保留收敛曲线及最终短窗口；用户可重新开始。重新开始/调参重置学习，普通暂停/恢复保留状态。

随机模式使用谱驱动的连续随机合成，超过40秒仍产生新样本；默认实录噪声模式使用固定四路素材同步平滑循环，输入会重复，但控制算法及路径状态连续保留。实录q保留所选四路耳噪声之间的时序关系；合成参考x来自教学R，不复现实录振动与耳噪声之间的真实可控性。S_hat=S仍为理想估计，不能将仿真降噪量当作实车试验结论。
