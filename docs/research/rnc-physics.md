# RNC 完整实验室：公开依据、教学模型与数值边界

更新：2026-09-24。对应 `lab-v3`，实现入口 `src/team-b/lab/index.ts`。旧 `demo-v2` 引擎和基准文件保持不变。本模型是可复现的低频机制教学，不是任何量产车的标定结果；车型间参数差别不构成车型优劣排名。

## 1. 硬件布置的依据

欧洲专利 [EP3156998B1，图2及描述](https://patents.google.com/patent/EP3156998B1/en) 展示机械连接至悬架的加速度参考传感器、座椅头枕处误差麦克风，以及经次级路径到达听音位置的扬声器。其多通道说明包含多个参考、扬声器和误差麦克风。本应用以四角悬架参考点作为默认布置，固定四个头枕附近误差点，用户可移置、增删参考点；具体坐标是原创双排 SUV 的教学安装位置，不声称复刻专利尺寸或任何车的量产方案。

四个车门扬声器按照需求建模。公开研究中门扬声器和头枕扬声器均存在；本模型不将“传感器越多”或“安装在任何位置”视作必然更好。移动参考点会改变四轮到参考点的幅值混合和时延，只有与干扰相关且足够提前的参考才有控制价值。

## 2. 四轮低频源 Q 的依据与简化

[Kindt 等，2009，Experimental analysis of the structure-borne tyre/road noise due to road discontinuities](https://www.sciencedirect.com/science/article/abs/pii/S0888327009001277)，DOI `10.1016/j.ymssp.2009.04.005`，实验研究速度、路面障碍、胎压和轮胎温度等影响。论文说明低频轮胎结构振动经轮毂、悬架传到车体并在座舱辐射，轮胎空腔首个共振通常位于约 200–250 Hz。由此采用低频宽带加结构/胎腔窄带成分的简化激励；不模拟高频胎路空气泵吸、风噪或发动机噪声。

[Cesbron 等，2009，Experimental study of tyre/road contact forces in rolling conditions for noise prediction](https://www.sciencedirect.com/science/article/pii/S0022460X08006317)，DOI `10.1016/j.jsv.2008.07.018`，对不同路面和滚动速度测量动态接触力与近场噪声。它支持将速度和路面纹理作为源输入，但不能为本模型选定的所有数值系数作背书。

本实现的四轮等效激励为：

```text
q_i[n] = A × {0.88 (h_band * ξ_i)[n]
              + 0.24 sin(2π f_s n/fs + φ_i)
              + 0.18 sin(2π f_c n/fs + 2φ_i)}
A = (v/60)^1.25 × sqrt(R) × (0.65 + 0.35 Tread)
    × 10^[−0.04(Temperature−20)/20]
f_s = 95 sqrt(Pressure/240) Hz
f_c = 220 sqrt((Temperature+273.15)/293.15) Hz
```

`ξ_i` 是由种子生成的独立均匀伪随机序列；`h_band` 是 97 点窗化 FIR，宽带约 35–360 Hz，窄带成分只表示两个理想化模态。`q` 的单位是等效轮端激励加速度 m/s²，不是实测声功率。其强度谱 `Q_i(f)` 为该确定性时序的功率谱；幅值因子 A 对应谱功率乘以 A²。可通过任意参考通道的频谱观察其经过结构传递后的影响。

参数表：

| 参数 | 本模型行为 | 证据强度与解释 |
| --- | --- | --- |
| 车速 v，0–130 km/h | 固定其它条件时幅值随速度增加；停车源归零 | 支持用于教学的一般趋势；1.25 是教学系数，不是拟合值 |
| 路面粗糙度 R，0.1–3 | 幅值按 sqrt(R) 增加 | 等效低频激励强度，不代表完整道路纹理谱或 ISO 等级 |
| 胎面粗糙度，0.1–3 | 低频激励幅值增加 | 抽象示意参数，不等同胎面花纹、磨耗或轮胎安全评价 |
| 胎压，160–320 kPa | 结构模态频率随 sqrt(P) 移动 | 受张力/刚度影响的教学假设；**未假设胎压越高噪声一定越大或越小** |
| 温度，−20–50 °C | 声速和胎腔频率随绝对温度平方根变化；源幅值有小幅温度修正 | 胎腔理想气体近似；幅值修正仅代表选定沥青教学情景 |

[Anfosso-Lédée 与 Pichaud，2007，Temperature effect on tyre–road noise](https://www.sciencedirect.com/science/article/pii/S0003682X06001344)，DOI `10.1016/j.apacoust.2006.06.001`，在多种路面研究温度效应，明确效应依赖胎路组合和路面。其外部通过噪声结果不能直接当作本项目低频座舱校准；这里 −0.04 dB/°C 是公开标注的演示假设，不是声称所有轮胎都成立的关系。胎压也不提供普遍单调的 SPL 结论。[Pinay 等的实验研究](https://publikationen.bibliothek.kit.edu/1000085202)，DOI `10.1016/j.apacoust.2018.07.023`，进一步说明胎腔测量和外部噪声之间需要具体数据建模。

## 3. 位置相关初级、次级路径

对任意物理位置 r，直接计算：

```text
d(r,n) = Σ_i H_i(r) * q_i[n]
a(r,n) = Σ_l S_l(r) * u_l[n]
e(r,n) = d(r,n) + a(r,n)
```

初级路径以四轮对应的地板辐射点表示“轮胎→悬架/车体→座舱”。传递包含有效结构延迟与空气传播距离、`1/(0.4+r)` 的近场正则化衰减、线性分数延迟及地板/顶棚两个早期镜像反射。次级路径从真实四门扬声器坐标出发，包含电子延迟、同样的距离与镜像反射、短低通核表示车门中低音单元与电子链路的有效频响。这里只建模采样可表示的低频响应，不推断扬声器直径就能决定完整频响。

四类车分别配置地板耦合增益、有效结构延迟、反射强度和舱顶高度，参数明确保存在 `VEHICLE_ACOUSTICS`。这些数值是可替换的教学配置，不是从“动力类型”推导出的实车固有定律。所有路径都因果、所有四轮和全部启用扬声器对每个误差点都有贡献。

本模型没有求解车体弹性方程、腔体完整模态或有限元网格。参考 COMSOL 仅指显示与物理量定义，不能称为 COMSOL 同精度仿真。[COMSOL 官方声学说明](https://www.comsol.com/multiphysics/acoustics) 说明声压叠加与空气参考声压；本项目在 SI 坐标中保持该物理量定义。

## 4. 真正动态多通道 FxLMS

N 路参考（1–8）产生四路输出，误差点固定四路。控制器包含 `W[output][reference][tap]`，四个误差共同驱动每组权值更新；不是四套彼此隔离的单通道算法。

```text
u_l[n] = Σ_k Σ_j W_lkj[n] x_k[n−j]
xFiltered_mlk = S_hat_ml * x_k
E[n] = epsilon + Σ_enabled_l Σ_m Σ_k Σ_j xFiltered_mlk[n−j]^2
W_lkj[n+1] = W_lkj[n]
  − μ / E[n] × Σ_m e_m[n] xFiltered_mlk[n−j]
```

这是归一化多通道 FxLMS，`e=d+a` 对应负梯度。演示采用理想已知次级模型 `S_hat=S`，没有伪装成在线辨识。学习从 2 秒开始，权值只在下一样本生效。关闭某扬声器意味着该输出 u 恒为零、该输出权值不更新；禁用 RNC 或步长为零时全部输出为零，e 精确等于 d。改变参考数/位置或扬声器开关会真正重新计算。

阶数16–128、归一化步长0–0.5。未经所有组合验证的参数可能收敛差或放大部分位置；发现非有限值/过大输出会明确报错，算法不通过限幅或更改 e 增益制造效果。理想次级模型和可预测源会使默认结果明显优于真实车辆，不作为商用降噪承诺。

## 5. 三维声场与度量

`sampleField` 对每个给定位置通过相同 q、u、H、S 求 d 与 e，再计算过去 0.5 秒的未计权 RMS。它不插值四个麦克风读数，也不按时间预设颜色或强制递减。空间其它位置可能恶化；视觉爆炸/剖切只改变展示，不能移动物理场的声学坐标。

```text
Lp(r) = 10 log10(mean(p(r,n)^2) / (20e−6 Pa)^2)
Reduction(r) = 10 log10(mean(d(r,n)^2) / mean(e(r,n)^2))
```

定义与 [COMSOL 的瞬态声压级说明](https://www.comsol.com/blogs/computing-transient-sound-pressure-levels-in-comsol/) 一致。窗口不足0.5秒返回 `valid=false`；停车等低于数值能量底噪时不显示伪造的有限声场。频谱是 1024 点 Hann/Welch 单边功率谱，窗口不足1024点为空。末4秒指标按真实平方压力统计，保持所有声道相同标度。

自动测试覆盖所有交叉路径、独立首步梯度、动态参考维度、禁用输出、RNC关闭、确定性、源趋势、同点同窗 SPL 一致性，以及非麦克风位置的全时序卷积对照。原有 fixture 测试不因本模块放宽或替换。GPU、耳机听感、实车测量与所有参数组合仍须独立验收。
