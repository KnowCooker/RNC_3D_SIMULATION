# A组最终交付标准（完整目标）

确认日期：2026-09-24。依据用户恢复的[完整目标](../plan/10_FULL_GOAL.md)及本次“重新确定最终A组需要交付的内容”。本文件定义最终要交什么，不以当前实现反推需求。旧两周清单移至[历史阶段交付](A_STAGE_V2_DELIVERY.md)，其中单车型、固定工况、不做空间声场等限制不再适用最终目标。

## 1. 最终交付是什么

A组交付可在Windows浏览器运行的**交互式车辆RNC展示、调试和试听应用**：理解四类SUV结构、RNC硬件位置、噪声传播和控制原理；调整工况、算法及硬件配置，观察真实计算的信号和空间声场，公平比较控制前后声音。

演示闭环：选车型 → 看结构/拆解/剖面 → 查看硬件与信号 → 改工况及参数 → 增减参考/启禁扬声器 → 运行实验 → 看时域/频域/学习过程/声场 → 同时间比较四座位原声与残余声。实验身份、参数、选择、数据和时间必须一致。

## 2. A2必须交付的三维系统

| ID | 必交内容 | 完成判据 |
| --- | --- | --- |
| A2-F1 | 四类双排SUV及结构资料 | ICE燃油、BEV纯电、HEV混动、EREV增程均可选，基本机械/电驱结构有专业公开依据，架构差异可辨。不能只改名称；不得把增程发动机错误连到驱动轮。可原创外形和尺寸，事实与教学简化分开说明 |
| A2-F2 | 外观与完整基本座舱 | 车身、四门、四轮、底盘、动力结构、两排座椅/头枕、方向盘、扶手箱齐全。以地平线系列车辆模型精细度为视觉参考，提交外观/内饰/结构对照并作视觉验收；不能用“能显示”或三角形数量代替质量判断 |
| A2-F3 | 三维交互 | 360度旋转、缩放、相机复位、连贯爆炸/收拢、透明/隐藏、可选剖面；组合操作不漂移、不丢结构，内部及截面关系可读。当前裁剪未封口属于需检查的质量缺口，不能只凭出现裁剪平面判定完成 |
| A2-F4 | RNC硬件与改制 | 底盘振动参考、四个头枕附近固定误差点、作为车门模型一部分的四扬声器；布置有研究/专利依据。改制模式可在可见结构/表面增减参考、启禁扬声器；不开放误差点改制 |
| A2-F5 | 点选及安装坐标一致性 | 3D点选/右键返回正确通道，q源与x参考区分。爆炸时参考随安装部件、扬声器随门、麦克风随座舱；收拢/重建不改物理坐标；车型切换后不存在的安装部件有明确处理 |
| A2-F6 | 声学可视化 | 四轮源、初级/次级传播路径、扬声器波前、车内三维SPL及切片。场值来自B组任意点计算，有固定色标/单位/时窗；随爆炸、剖面、暂停、定位正确变化；禁用输出反馈真实。示意波前与计算压力必须区分 |
| A2-F7 | 三维质量与交接 | 四车型截图、组合交互复测、目标设备性能、演示录像、结构来源/资产许可、接口说明、已知问题；旧运行版本证据不能证明新版通过 |

A2负责几何与渲染，不自行生成降噪数据。为显示进行场插值时保留真实空间采样依据；不能只插值四个麦克风冒充任意点物理计算。

## 5. 最终交付物

1. **完整源码**：A1/A2模块、接口、资产/资料出处、锁文件、脚本与测试，定位到已集成源码版本。
2. **Windows可运行包**：默认完整实验、运行资源、启动脚本；明确环境前提，无运行时CDN/在线模型/AI API依赖，不以双击HTML代替HTTP启动。
3. **操作与原理说明**：车型、三维操作、改制/调参、信号、试听、场值解释、错误恢复、运行方式及限制。
4. **验收报告与证据**：按A1-F/A2-F编号记录代码版本、机器/GPU/浏览器、配置、步骤、结果/待测项，保存脚本、数值、截图及包哈希。
5. **演示材料**：约五分钟讲解和录像，覆盖车型、结构/剖面、改制、信号、调参、声场和声音对比；录像不能代替实物验收。
6. **可接续记录**：当前任务、已完成/未完成项、准确下一步、文件边界、提交/PR及验证入口，另一位成员的Codex仅凭仓库即可继续。

正式包、源码与报告必须对应同一运行版本。开放PR、本机可运行、main已集成分别记录。

## 6. 最终验收门槛

- 逐项走完A1-F1～F7和A2-F1～F7；核对结构与视觉质量，不只检查菜单存在。
- 工况/改制真实改变引擎输入和结果；RNC关闭、零步长、禁用输出有数值证据，不承诺所有工况每一点必然降噪。
- 场由四轮源和输出路径叠加；同位置/同窗的场值与误差信号指标一致；剖面/爆炸不修改物理坐标。
- 最新运行版本通过类型、边界、相关测试、生产构建及全车型组合操作回归。
- 新版连续演示20分钟、至少10次重算、20次播放/对比切换，无崩溃、失控队列、明显持续内存增长；实时模式另覆盖持续计算和停止/重启。
- 沿用设备目标：指定核显、1080p窗口/1280×720内部渲染平均至少30fps；默认计算目标5秒内；实物音画偏差目标≤100ms，无可感知爆音；第二台Windows真实断网启动并重开3次。未达到时记录支持限制，不能用独显/模拟断网替代并称全部通过。
- 完成集成、版本/包校验、说明及交接。权限未就绪可交分支/PR，不写成main已经合并。
